El modelo de caja

Todo elemento HTML es, para CSS, una caja rectangular formada por cuatro capas, unas dentro de otras:

margin (espacio exterior, fuera de la caja)

border (el borde de la caja)

padding (espacio interior, dentro del borde)

content (tu texto, tu imagen...)

Las cuatro capas, de dentro hacia afuera:

CapaQué es
contentEl contenido real: el texto, la imagen...
paddingEspacio entre el contenido y el borde, por dentro
borderEl borde de la caja, entre el padding y el margin
marginEspacio fuera de la caja, que la separa de las demás
🤔 Truco para no confundirte: el padding empuja tu contenido "hacia dentro" (aleja el texto del borde); el margin empuja la caja entera "hacia fuera" (la aleja de sus vecinas).

Ejercicio guiado 1 — Ver las capas con tus propios ojos

  1. En tu prueba-css.html de la sesión pasada, añade un <div> nuevo con class="tarjeta" y un poco de texto dentro.
  2. Créale una regla .tarjeta con background-color claro y color oscuro, para que se distinga del fondo.
  3. Añade border: 3px solid red; a esa misma regla, guarda y observa dónde aparece el borde: justo pegado al fondo de color, sin ningún espacio.

Si lo has hecho bien: verás un borde rojo grueso tocando directamente el texto y el fondo de color, sin ningún hueco — porque todavía no has añadido padding.

Padding: espacio interior

padding aleja el contenido del borde. Se puede escribir con un valor único (igual en los cuatro lados), con dos valores (arriba/abajo y izquierda/derecha) o con cuatro valores (uno por lado, en el orden arriba-derecha-abajo-izquierda):

.tarjeta {
    padding: 20px; /* los cuatro lados iguales */
}
Sin padding
Con padding: 20px

Con dos valores, el primero manda arriba/abajo y el segundo izquierda/derecha:

.tarjeta {
    /* arriba/abajo: 10px, izquierda/derecha: 30px */
    padding: 10px 30px;
}
padding: 10px 30px;

Y con cuatro valores controlas cada lado por separado, sin necesidad de usar padding-top, padding-right, etc. uno a uno:

.tarjeta {
    /* arriba - derecha - abajo - izquierda */
    padding: 6px 24px 30px 6px;
}
padding: 6px 24px 30px 6px;
El orden de los cuatro valores es siempre el mismo (arriba, derecha, abajo, izquierda) — se recuerda pensando en las agujas de un reloj empezando arriba. También existen padding-top, padding-right, padding-bottom y padding-left para tocar un único lado sin escribir los demás.

Ejercicio guiado 2 — Añade padding

  1. A tu regla .tarjeta, añade padding: 20px;.
  2. Observa cómo ahora el texto ya no toca el borde rojo.
  3. Cambia el padding a 10px 30px; (dos valores) y fíjate en la diferencia entre el espacio de arriba/abajo y el de los lados.

Si lo has hecho bien: con 10px 30px verás claramente más aire a los lados que arriba y abajo — si los cuatro lados se vieran iguales, algo no se ha guardado o el selector no coincide.

Border: el borde de la caja

border se suele escribir en una sola línea, con tres valores seguidos: grosor, estilo y color.

.tarjeta {
    border: 2px solid #3c3c3c;
    border-radius: 6px;
}
solid
dashed
solid + border-radius
border-radius no forma parte del borde en sí, pero se usa casi siempre junto a él para redondear las esquinas de la caja — así se ven las "tarjetas" que probablemente ya conoces de otras webs.

Ejercicio guiado 3 — Bordes con estilo

  1. Cambia el border de tu .tarjeta a 2px solid #3c3c3c; (en vez del rojo grueso de antes).
  2. Añade border-radius: 6px; a la misma regla.
  3. Prueba border-style: dashed; en vez de solid y observa el cambio.

Si lo has hecho bien: el borde grueso rojo habrá desaparecido, sustituido por uno fino gris con las esquinas redondeadas; al cambiar a dashed se verá a rayas en vez de continuo.

Margin: espacio exterior

margin funciona igual que padding en la forma de escribirlo (uno, dos o cuatro valores), pero separa la caja de las cajas vecinas, no de su propio contenido:

.tarjeta {
    margin: 16px;
}
Tarjeta 1
Tarjeta 2 (separada de la anterior por el margin)

Un caso especial muy útil: si una caja tiene un width fijo, margin: 0 auto; la centra horizontalmente en su contenedor (el 0 es el margin arriba/abajo, y auto reparte el espacio sobrante a izquierda y derecha por igual):

.tarjeta-centrada {
    width: 220px;
    margin: 0 auto;
}
width: 220px; margin: 0 auto;
🤔 Antes de seguir: si a esa misma caja le quitas el width: 220px; y dejas solo margin: 0 auto;, ¿crees que se seguirá viendo centrada?
Ver la respuesta

No — sin un width fijo, una caja normal (como un <div>) ya ocupa todo el ancho disponible de su contenedor por defecto, así que no queda ningún "espacio sobrante" que repartir a los lados y margin: 0 auto; no tiene ningún efecto visible. margin: 0 auto; solo centra cajas que ya son más estrechas que su contenedor.

Ejercicio guiado 4 — Separa tus tarjetas

  1. Duplica tu <div class="tarjeta"> para tener dos tarjetas seguidas en prueba-css.html.
  2. Añade margin-bottom: 16px; a la regla .tarjeta y comprueba que ahora hay espacio entre ellas.
  3. Dale a una de las dos tarjetas un width: 300px; y un margin: 0 auto; propios (en una regla o clase aparte), y observa cómo se centra.

Si lo has hecho bien: tus dos tarjetas ya no estarán pegadas entre sí, y la que tiene width y margin: 0 auto; quedará centrada horizontalmente con el mismo hueco a su izquierda que a su derecha.

Width, height... y una trampa importante

width y height fijan el tamaño de la caja de contenido. El problema: por defecto, el padding y el border se suman a ese tamaño, así que la caja acaba siendo más grande de lo que esperabas.

.caja-300 {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
}
/* ancho visible real: 300 + 20+20 + 5+5 = 350px, no 300px */
width: 300px + padding + border → esta caja mide en realidad 350px de ancho, aunque el CSS diga 300px
⚠️ Esta es la sorpresa más habitual al empezar con CSS: pones width: 300px y la caja no mide 300px en pantalla. De momento, calcula el ancho real sumando width + padding (los dos lados) + border (los dos lados).

Ejercicio guiado 5 — Aplícalo a tu propia web

  1. Abre tu estilos.css (el de tu web personal, no el de prueba).
  2. Elige dos o tres bloques de tu página (por ejemplo tus <section>) y dales una clase común, por ejemplo class="bloque".
  3. Crea la regla .bloque con padding, border, border-radius y margin-bottom, para que cada bloque se vea como una tarjeta separada de las demás.

Si lo has hecho bien: con Live Server verás cada bloque como una tarjeta independiente, sin tocarse entre sí ni pegarse al borde de la pantalla.

⚠️ Recuerda: todo esto va en estilos.css, el archivo externo — nunca en un <style> suelto dentro de tu index.html.

Retos

Los tres retos son obligatorios, en orden: cada uno se apoya en el anterior. Si te atascas en alguno, dilo — es normal no encontrar la solución a la primera y para eso estoy yo.

Reto 1 — Tarjetas consistentes

Aplica el mismo padding, el mismo border (o el mismo border-radius) a todos los bloques de tu web que quieras que parezcan tarjetas — no vale que cada uno tenga un padding distinto "porque sí". La consistencia se consigue reutilizando la misma clase, no copiando valores parecidos en reglas distintas.

Reto 2 — Investiga: box-sizing: border-box

Esta propiedad no la hemos explicado en clase, y resuelve justo la trampa de width que has visto antes. Entra en la referencia de MDN sobre box-sizing y busca qué valor de esta propiedad hace que el padding y el border dejen de sumarse al width que defines. Añádela a tus reglas.

Pista si te atascas

En la página de MDN, mira la tabla de "Valores" de box-sizing: hay dos, y el que buscas no es el que trae el navegador por defecto (ese es el que produce la trampa que has visto antes). Su nombre en inglés menciona la palabra "border".

Reto 3 — Todo junto

Revisa tu web completa y comprueba que cumple todo esto a la vez:

  • Tienes al menos dos bloques con aspecto de "tarjeta" (padding + border + border-radius), usando una clase reutilizada.
  • Ningún bloque toca el borde de la pantalla ni el bloque de al lado — hay margin donde corresponde.
  • Aplicas box-sizing: border-box del Reto 2 a esos bloques.
  • Todo el CSS sigue en tu archivo estilos.css externo.
Guarda esta versión — tu web ya tiene estructura, color, tipografía y ahora también espaciado con sentido.
