Palabras que se confunden

Estas parejas son la causa de la mayoría de los malentendidos al empezar. Si te aclaras con ellas, entenderás mucho mejor los enunciados.

Etiqueta y elemento

La etiqueta es lo que escribes entre < y >. El elemento es el conjunto completo: etiqueta de apertura + contenido + etiqueta de cierre.

<p>Hola</p>
/* <p> y </p> son etiquetas. Todo junto es un elemento. */

Por eso se dice "la etiqueta <img> no se cierra", pero también "el elemento <p> contiene texto".

Atributo, propiedad y valor

Es la confusión más habitual, porque las dos primeras palabras suenan parecidas pero viven en lenguajes distintos:

PalabraDónde viveEjemplo
AtributoEn HTML, dentro de una etiqueta<img src="foto.jpg"> → src
PropiedadEn CSS, dentro de una reglacolor: red; → color
ValorEn los dos: lo que va después del = o del :"foto.jpg", red
Regla rápida: si lo escribes dentro de una etiqueta y lleva = y comillas, es un atributo. Si lo escribes dentro de unas llaves y lleva : y punto y coma, es una propiedad.

Regla, selector y declaración

Una regla CSS completa tiene dos partes: el selector (a quién afecta) y las declaraciones entre llaves (qué le hace). Cada declaración es una pareja propiedad + valor.

h1 {                    /* h1 = selector */
    color: darkblue;      /* esto es una declaración */
    text-align: center;  /* esto es otra declaración */
}                       /* todo junto: una regla */

El id tiene doble vida: en la sesión 2 lo usaste como destino de un enlace ancla (href="#css" salta al elemento con id="css"), y en la sesión 4 como selector de CSS. Es el mismo atributo haciendo dos trabajos distintos.

padding y margin

Las dos crean espacio, pero en lados distintos del borde:

PropiedadDónde crea el espacioEfecto
paddingPor dentro del bordeAleja tu contenido del borde de su propia caja
marginPor fuera del bordeAleja la caja entera de las cajas vecinas

Truco: si el fondo de color del elemento crece, era padding. Si crece el hueco pero el fondo no, era margin.

width: a veces atributo, a veces propiedad

La misma palabra aparece en los dos lenguajes y no son lo mismo:

<!-- En HTML: atributo, solo para imágenes -->
<img src="foto.jpg" alt="..." width="220">

/* En CSS: propiedad, para cualquier caja */
.tarjeta {
    width: 300px;
}
Fíjate en la diferencia de escritura: en HTML va sin unidad y entre comillas (width="220"); en CSS va con unidad y sin comillas (width: 300px;).

Tabla de datos y tabla de maquetación

Una tabla de datos (<table>) es para información real organizada en filas y columnas: un horario, una clasificación. Una tabla de maquetación es usar esa misma etiqueta solo para colocar bloques de la página en columnas — algo que este curso no enseña, porque mezcla estructura de datos con diseño visual. Si ves una página (o un examen) cuyo código use <table> para organizar el layout general, la técnica correcta para replicarlo es Flexbox, no una tabla, aunque el original esté hecho de otra forma.

Selector y pseudo-clase

Un selector normal (p, .tarjeta, #cabecera) afecta al elemento siempre. Una pseudo-clase como :hover se pega detrás de un selector y solo aplica el estilo bajo una condición — en este caso, mientras el ratón está encima.

.boton {                  /* selector: siempre */
    background-color: #3c3c3c;
}
.boton:hover {            /* selector + pseudo-clase: solo con el ratón encima */
    background-color: #3a9bd1;
}

El entorno de trabajo

Vocabulario que no es HTML ni CSS, pero que aparece en todos los enunciados.

PalabraQué significa
Carpeta de proyectoLa carpeta que contiene todos los archivos de tu web (mi-web). En programación no se trabaja con archivos sueltos: se abre la carpeta entera en VS Code.
ExtensiónLo que va después del punto en el nombre del archivo (.html, .css, .jpg). Le dice al ordenador qué tipo de archivo es. Si la extensión está mal, el archivo no funciona aunque el contenido sea correcto.
index.htmlEl nombre que se le da por convención a la página principal de un sitio web.
RutaLa dirección que indica dónde está un archivo. Es lo que escribes en src y en href.
Ruta relativaUna ruta que se lee desde el archivo que la escribe. src="foto.jpg" significa "una foto que está en la misma carpeta que este HTML".
Live ServerLa extensión de VS Code que abre tu página en el navegador y la recarga sola cada vez que guardas.
Guardar (Ctrl+S)Hasta que no guardas, el navegador sigue viendo la versión antigua. Si un cambio "no se ve", lo primero es comprobar si has guardado.
Código fuenteEl HTML y el CSS con los que está hecha una página. Se puede ver en cualquier web con Ctrl+U.
RenderizarLo que hace el navegador: leer tu código y dibujar la página en pantalla.
⚠️ El fallo número uno cuando "no aparece la imagen" o "no se aplica el CSS" es la ruta: el nombre escrito en src o href no coincide exactamente con el archivo real, o el archivo está en otra carpeta. Mayúsculas, espacios y extensión cuentan.

Cómo se escribe cada cosa, para copiar la forma (no el contenido) cuando no te acuerdes.

Estructura de una página

<!DOCTYPE html>
<html>
<head>
    <title>Título de la pestaña</title>
    <link rel="stylesheet" href="estilos.css">
</head>
<body>
    <!-- Aquí va todo lo que se ve -->
</body>
</html>

Reglas CSS

/* Por etiqueta: todos los <p> de la página */
p {
    font-size: 1.1em;
}

/* Por clase: todo lo que tenga class="destacado" */
.destacado {
    color: darkred;
}

/* Por id: el único elemento con id="cabecera" */
#cabecera {
    background-color: #2d2d30;
}

/* Una tarjeta con caja completa */
.tarjeta {
    padding: 20px;
    border: 2px solid #3c3c3c;
    border-radius: 6px;
    margin-bottom: 16px;
    box-sizing: border-box;
}
Los comentarios se escriben distinto en cada lenguaje: en HTML <!-- así -->, en CSS /* así */. No son intercambiables.

Tablas de datos

<table>
    <tr>
        <th>Asignatura</th><th>Horas</th>
    </tr>
    <tr>
        <td>Informática</td><td>5</td>
    </tr>
    <tr>

    </tr>

⚠️ Si fusionas una celda con colspan, esa fila tiene que tener menos celdas que las demás (las que fusiona ya no se escriben aparte) — si no, la tabla se descuadra.

Flexbox

.contenedor {
    display: flex;
    flex-wrap: wrap;
    gap: 16px;
    justify-content: center;
}
Flexbox organiza bloques enteros entre sí (una fila de tarjetas, un menú). No confundir con el modelo de caja, que describe una caja por dentro (padding, border, margin).

Imagen de fondo y :hover

.franja {
    background-image: url("icono.png");
    background-repeat: repeat-y;
}

.boton {
    cursor: pointer;
}
.boton:hover {
    background-color: #3a9bd1;
}

Si algo no te funciona

Antes de preguntar, comprueba esta lista. Resuelve la mayoría de los casos.

  • ¿Has guardado el archivo? (Ctrl+S)
  • ¿El nombre del archivo en src o href coincide exactamente con el archivo real, incluida la extensión y las mayúsculas?
  • ¿El archivo está en la misma carpeta que el HTML que lo llama?
  • ¿Has cerrado todas las etiquetas que había que cerrar?
  • En CSS: ¿falta algún punto y coma, o alguna llave de cierre? Una llave sin cerrar hace que se ignore todo lo que viene después.
  • En CSS: ¿has escrito el . de la clase o la # del id en el selector?
  • ¿El texto se ve del mismo color que el fondo? (mira si has puesto background-color sin cambiar el color)
  • Si usas colspan, ¿esa fila tiene el número correcto de celdas escritas (las que fusiona ya no van aparte)?
  • ¿Tu contenedor flex tiene display: flex? Sin esa línea, flex-wrap, gap, justify-content y align-items no hacen nada.
