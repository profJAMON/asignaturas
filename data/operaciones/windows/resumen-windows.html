Ronda rápida

Las respuestas están escondidas: las vemos juntos.

Si minimizas una ventana, el programa se cierra.

  1. Verdadero
  2. Falso

Falso: se esconde en la barra de tareas y sigue abierto. (Sesión 1)

¿Qué atajo esconde todas las ventanas y enseña el escritorio?

  1. Windows + E
  2. Windows + D
  3. Alt + F4

Windows + D. Windows + E abre el Explorador y Alt + F4 cierra la ventana. (Sesión 1)

Borras un acceso directo del Escritorio. La carpeta original…

  1. se borra también
  2. sigue en su sitio
  3. va a la Papelera

Sigue en su sitio: el acceso directo solo apunta al original. (Sesión 2)

Lo que borras de un USB va a la Papelera.

  1. Verdadero
  2. Falso

Falso: de un USB se borra para siempre. (Sesión 2)

Un vídeo de 6 GB no cabe en un USB con 20 GB libres. ¿Por qué?

  1. el USB está en FAT32
  2. el USB está roto
  3. hay que vaciar la Papelera

FAT32 no admite archivos de más de 4 GB. Se formatea en exFAT o NTFS. (Sesión 3)

Para el día a día, la cuenta más segura es…

  1. administrador
  2. usuario estándar
  3. sin contraseña

Estándar: si se cuela un virus, no puede cambiar el sistema. (Sesión 4)

Un programa pone «No responde». ¿Qué atajo abre el Administrador de tareas?

  1. Ctrl + Shift + Esc
  2. Ctrl + Z
  3. Windows + L

Ctrl + Shift + Esc → elegir el programa → Finalizar tarea. (Sesión 5)

Si marcas «Permitir» y «Denegar» en la misma casilla, gana…

  1. Permitir
  2. Denegar

Denegar manda siempre. Por eso, para quitar un permiso, se desmarca «Permitir». (Sesión 5)
