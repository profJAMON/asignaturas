Las partes del escritorio

Cuando entras en Windows, lo primero que ves es el escritorio. Pasa las diapositivas para ver cada parte:

1. El escritorio es el fondo de la pantalla. Encima hay iconos: la Papelera, carpetas y accesos directos.

2. Abajo está la barra de tareas: siempre a la vista, aunque tengas ventanas abiertas.

3. El primer botón es Inicio (los cuatro cuadrados): abre el menú con todos los programas.

4. Al lado, las aplicaciones: las ancladas siempre están; las que están abiertas llevan una rayita debajo.

5. A la derecha, el área de notificación: la hora, la fecha, el wifi, el volumen y el idioma del teclado.

6. Cada programa abierto es una ventana. Puedes tener muchas abiertas a la vez.

PartePara qué sirve
EscritorioEl fondo, con iconos de la Papelera, carpetas y accesos directos.
Barra de tareasLa barra de abajo: Inicio, buscar y las aplicaciones.
Botón InicioAbre el menú Inicio con todos los programas.
Aplicaciones de la barraLas ancladas están siempre; las abiertas llevan una rayita debajo.
Área de notificaciónA la derecha: hora, fecha, wifi, volumen e idioma del teclado.

Actividad 1 — Mira tu escritorio

Ahora en tu ordenador de verdad.

  1. Minimiza el navegador para ver tu escritorio.
  2. Mira la barra de tareas: ¿qué aplicaciones están ancladas? ¿Cuál tiene la rayita de «abierta»?
  3. Mira el área de notificación: ¿qué pone en el idioma del teclado (por ejemplo, ESP)?
  4. Apunta en tu cuaderno las aplicaciones ancladas de tu barra de tareas, cuál está abierta y qué idioma de teclado sale (pregunta 4).

Comprobación observable: has vuelto al navegador desde la barra de tareas y la web sigue donde estaba.

El menú Inicio

Se abre con el botón Inicio o con la tecla Windows (la de los cuatro cuadrados, entre Ctrl y Alt).

  • Arriba tiene un buscador: no hace falta hacer clic en él, basta con abrir Inicio y escribir el nombre del programa.
  • Debajo, las aplicaciones ancladas. El botón «Todas» enseña la lista completa, por orden alfabético.
  • Abajo a la derecha, el botón de apagar: Suspender, Apagar o Reiniciar.
  • Con clic derecho en una aplicación: «Anclar a la barra de tareas» (o «Desanclar»). Así la tienes siempre a mano.
  • Con clic derecho en el botón Inicio (o Windows + X) sale otro menú con herramientas: Administrador de tareas, Configuración, Administrador de dispositivos…
⚠️ Para apagar el ordenador, siempre desde Inicio → Apagar. Si lo apagas con el botón de la torre, puedes perder lo que no esté guardado y estropear archivos.

Las ventanas

Cada programa abierto es una ventana. Todas tienen las mismas partes:

1. Arriba, la barra de título: dice qué programa es. Arrastrándola, mueves la ventana.

2. Minimizar (–) esconde la ventana en la barra de tareas. No se cierra: sigue abierta.

3. Maximizar (▢) la pone a pantalla completa. Si ya lo está, el botón la restaura a su tamaño.

4. Cerrar (✕) cierra el programa. Si no has guardado, te pregunta antes.

Dos ventanas a media pantalla

Muchas veces quieres ver dos cosas a la vez: el enunciado y tu trabajo, por ejemplo. Windows las ajusta solas:

1. Arrastra la ventana por su barra de título hasta el borde izquierdo de la pantalla (o pulsa Windows + ←).

2. La ventana ocupa justo la mitad de la pantalla.

3. Haz lo mismo con otra hacia la derecha (Windows + →): las dos a la vez, sin taparse. Va muy bien para copiar de una a otra.

🤔 Antes de seguir: has minimizado el Bloc de notas. ¿Lo has cerrado? ¿Cómo lo recuperas?
Ver respuestaNo: minimizar solo lo esconde. Sigue abierto, con su rayita en la barra de tareas. Lo recuperas haciendo clic en su botón de la barra (o con Alt + Tab).

Los atajos de teclado

Un atajo es una combinación de teclas que hace lo mismo que varios clics. Se pulsa así: mantienes la primera tecla (Windows, Ctrl, Alt…) y, sin soltarla, pulsas la otra.

AtajoQué hace
WindowsAbre o cierra el menú Inicio
Windows + EAbre el Explorador de archivos
Windows + DEsconde todas las ventanas y enseña el escritorio (otra vez, las vuelve a enseñar)
Alt + TabCambia de ventana: mantén Alt y pulsa Tab hasta llegar a la que quieres
Windows + ← / Windows + →Pone la ventana en la mitad izquierda / derecha
Windows + ↑Maximiza la ventana
Alt + F4Cierra la ventana que estás usando
Windows + LBloquea el ordenador (hace falta la contraseña para volver)
Windows + IAbre la Configuración
Windows + XAbre el menú del clic derecho en Inicio

Practica: lee qué quieres hacer y escribe el atajo (por ejemplo, Windows + E).

Actividad 2 — Prueba los atajos en tu ordenador

En tu Windows de verdad. Antes, guarda lo que estés haciendo.

  1. Pulsa Windows + E. Después Windows + D y otra vez Windows + D.
  2. Con dos ventanas abiertas, mantén Alt y pulsa Tab varias veces. Suelta Alt.
  3. Pulsa Windows + L. Vuelve a entrar con tu contraseña.
  4. Apunta en tu cuaderno qué ha pasado con cada uno de los cuatro atajos (pregunta 11).

Comprobación observable: después de Windows + L sale la pantalla de bloqueo con la hora, y al volver a entrar todo está como lo dejaste.

Actividad 3 — Organiza las ventanas

Ahora en un Windows 11 de mentira, que funciona como el de verdad: Inicio, barra de tareas, clic derecho, arrastrar y atajos. Tu ordenador de verdad se queda algunos atajos (los de la tecla Windows y Alt + Tab): esos, púlsalos en el teclado de debajo de la pantalla. Ctrl, Alt, Shift y Windows se quedan pulsadas hasta que tocas la siguiente tecla.

  1. Lee la misión (el pósit amarillo).
  2. Para abrir el Explorador, la misión pide el atajo, no el ratón. Para cambiar de ventana, también.
  3. Cuando salga «¡Misión cumplida!», apunta en tu cuaderno cómo has hecho cada una de las cinco cosas: el atajo o dónde has hecho clic (pregunta 13).

Comprobación observable: la Calculadora tiene su botón en la barra de tareas y, al final, solo se ve el escritorio.
