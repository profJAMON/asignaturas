Linux Mint, Ubuntu y Debian llevan el mismo núcleo.

  1. Verdadero
  2. Falso

Verdadero: son distribuciones de Linux; cambia lo de encima del núcleo. (Sesión 1)

¿Qué atajo abre la Terminal en Linux Mint?

  1. Windows + E
  2. Ctrl + Alt + T
  3. Ctrl + Alt + D

Ctrl + Alt + T. Windows + E abre el Gestor de archivos y Ctrl + Alt + D enseña el escritorio. (Sesión 1)

En Linux, Foto.png y foto.png pueden estar en la misma carpeta.

  1. Verdadero
  2. Falso

Verdadero: en Linux las mayúsculas cuentan. (Sesión 2)

Estás en /home/alumno y escribes cd ... ¿Dónde estás?

  1. /home
  2. /

cd .. sube una carpeta: /home. (Sesión 3)

Lo que borras con rm va a la papelera.

  1. Verdadero
  2. Falso

Falso: rm borra para siempre. (Sesión 3)

Un USB para el Linux de casa, el Windows del instituto y la tele, con vídeos de 6 GB:

  1. ext4
  2. FAT32
  3. exFAT

exFAT: lo leen todos y admite archivos de más de 4 GB. Windows no lee ext4. (Sesión 4)
