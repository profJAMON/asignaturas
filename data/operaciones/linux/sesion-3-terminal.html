Qué es la terminal

La terminal es una ventana donde escribes órdenes (también se llaman comandos) en lugar de hacer clic. Ya usaste una en la Unidad 2: el cmd de Windows, con ipconfig y ping. Se abre con Ctrl + Alt + T.

¿Para qué, si hay ratón?

  • Muchas cosas son más rápidas: mover 200 fotos con una sola orden.
  • Los servidores no tienen pantalla ni ratón: se manejan solo con la terminal. El de BloqueCraft, también.
  • Las órdenes son las mismas en todas las distribuciones, aunque cada una tenga su escritorio.

Lo que te enseña antes de escribir

Antes del sitio donde escribes sale el prompt. Pasa las diapositivas para ver qué te dice:

1. Primero, tu usuario: quién está escribiendo.

2. Después de la @, el nombre del ordenador.

3. Después de los dos puntos, la carpeta en la que estás. ~ es tu carpeta personal.

4. Al final, $ si eres un usuario normal; # si eres el administrador (root).

Cómo se escribe una orden

Una orden tiene hasta tres partes, separadas por espacios:

ls  -l  Documentos
│   │   └─ sobre qué: un archivo o una carpeta
│   └───── opciones: empiezan por un guion
└───────── la orden
  • Se ejecuta con Intro.
  • Las mayúsculas cuentan: LS no existe; ls, sí.
  • El espacio separa las partes. Por eso los nombres sin espacios (la norma de clase) son más cómodos: un nombre con espacio va entre comillas: cd "Mis cosas".

Moverse por las carpetas

OrdenQué haceEjemplo
pwdDice en qué carpeta estáspwd → /home/alumno
lsEnseña lo que hay en la carpeta (carpetas en azul)ls
ls -aTambién los ocultos (los que empiezan por punto)ls -a
ls -lCon todos los detalles: permisos, dueño, tamaño y fechals -l Documentos
cd carpetaEntra en una carpetacd Documentos
cd ..Sube a la carpeta de arribacd ..
cd o cd ~Vuelve a tu carpeta personalcd
cd /Va a la raízcd /

1. pwd: estás en /home/alumno, tu carpeta personal.

2. cd Documentos: entras. El prompt ya dice ~/Documentos.

3. cd ..: subes a la carpeta de arriba, otra vez a la tuya.

4. cd / te lleva a la raíz; cd solo, vuelta a tu carpeta estés donde estés.

Trucos que ahorran mucho

  • Tab completa el nombre: escribe cd Doc, pulsa Tab y sale cd Documentos/. Así no te equivocas y no tienes que escribir tildes (Im + Tab → Imágenes/).
  • La flecha ↑ vuelve a sacar las órdenes que ya escribiste.
  • clear (o Ctrl + L) limpia la pantalla.
  • Ctrl + C cancela la orden que se está escribiendo o haciendo. En la terminal no copia: para copiar y pegar se usan Ctrl + Shift + C y Ctrl + Shift + V.

Crear, copiar, mover y borrar

OrdenQué haceEjemplo
mkdirCrea una carpetamkdir fotos
touchCrea un archivo vacíotouch notas.txt
cpCopia (el original se queda)cp notas.txt fotos
cp -rCopia una carpeta enteracp -r fotos fotos-copia
mvMueve (el original desaparece de su sitio)mv foto.png fotos
mvCambia el nombremv notas.txt viejo.txt
rmBorra un archivorm viejo.txt
rm -rBorra una carpeta con todo lo de dentrorm -r fotos-copia
catEnseña lo que hay escrito en un archivocat notas.txt

Se puede usar una ruta en cualquiera de ellas: cp ~/Descargas/mapa.png ~/Imágenes. Y el asterisco quiere decir «cualquier cosa»: mv *.png fotos mueve todas las imágenes .png.

⚠️ rm no usa la papelera: lo que borras se borra para siempre. Antes de pulsar Intro, mira bien lo que has escrito.
