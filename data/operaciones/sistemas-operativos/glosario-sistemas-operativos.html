Palabras que se confunden

Gratis y libre

GratisLibre
Qué quiere decirNo pagas por usarloPuedes usarlo, ver cómo está hecho, cambiarlo y compartirlo
EjemploChrome, WhatsApp (gratis, pero propietarios)Linux, LibreOffice, VLC (libres y gratis)

Sistema operativo, aplicación y controlador

El sistema operativo manda en el ordenador. Las aplicaciones las usas tú y le piden todo al sistema operativo. Los controladores le explican al sistema operativo cómo se usa cada aparato.

Linux y distribución

Linux es el sistema operativo. Una distribución es una versión de Linux ya preparada para instalar, con su escritorio y sus programas: Ubuntu, Linux Mint…

Anfitrión e invitado

El anfitrión es el ordenador real y su sistema operativo (tu PC con Windows). El invitado es el sistema operativo que va dentro de la máquina virtual (Linux).

Hipervisor de tipo 1 y de tipo 2

Tipo 1: va directamente sobre el hardware; lo usan los servidores. Tipo 2: va encima de un sistema operativo, como un programa más; es VirtualBox en tu PC.

PalabraQué es
HardwareLa parte del ordenador que se puede tocar
SoftwareLos programas: instrucciones que no se pueden tocar
Sistema operativoEl programa que manda en el ordenador y deja funcionar a los demás
AplicaciónUn programa que usas para hacer algo: escribir, navegar, jugar
Controlador (driver)Programa que le explica al sistema operativo cómo se usa un aparato
Código fuenteEl texto que escribe el programador: la «receta» del programa
Software libreEl que puedes usar, ver cómo está hecho, cambiar y compartir
Software propietarioEl que solo puedes usar, y como diga su dueño
LicenciaEl permiso para usar un programa: dice qué puedes hacer y qué no
Licencia OEMViene con el ordenador nuevo y va pegada a él
Licencia retailLa compras aparte; se puede pasar a otro ordenador
Licencia por volumenMuchas licencias de golpe para una empresa o un instituto
Máquina virtualUn ordenador de mentira, hecho de software, dentro de uno de verdad
HipervisorEl programa que crea y arranca las máquinas virtuales (VirtualBox)
Disco virtualEl disco de la máquina virtual; para Windows, un archivo grande (.vdi)
ISOUn archivo que es la copia exacta de un disco de instalación
BIOS / UEFIEl programa de la placa base que arranca antes que el sistema operativo
Orden de arranqueLa lista de dónde busca el ordenador con qué arrancar: disco, USB, red…
ParticiónUn trozo de un disco que el sistema ve como un disco aparte (C:, D:)
Post-instalaciónLo que se hace justo después de instalar: actualizaciones, controladores e instantánea
ActualizaciónUn arreglo del sistema: corrige fallos y agujeros de seguridad
InstantáneaUna «foto» de la máquina virtual para volver a ese momento si algo se rompe
