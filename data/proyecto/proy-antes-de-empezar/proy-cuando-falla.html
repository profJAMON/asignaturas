Esta página es para cuando algo no funciona y no sabes por qué. Busca lo que ves en tu pantalla y prueba lo que dice, en orden. En cada caso hay un ejemplo roto que puedes arreglar aquí mismo.

Antes de nada: tres cosas que arreglan la mitad de los fallos

  1. Guarda: Ctrl + S en cada pestaña de VS Code. Una pestaña con un punto blanco está sin guardar.
  2. Recarga Chrome con Ctrl + F5.
  3. Abre la consola: F12 → Console. Si hay algo en rojo, léelo: dice el archivo y la línea.

No sale la imagen

Lo que ves: un icono de imagen rota o el texto del alt en lugar de la foto.

  • La imagen se llama tierra.png, en minúsculas. Arregla el src y mira cómo aparece.
Prueba esto (1): el nombre

El src tiene que ser exactamente el nombre del archivo: mayúsculas, minúsculas, guiones y la extensión (.jpg, .png, .webp). En la web publicada, Tierra.png y tierra.png son archivos distintos.

Prueba esto (2): la carpeta

Si la imagen está en la carpeta img, el src empieza por img/. Mira en VS Code, a la izquierda, que la imagen está de verdad dentro de img y no en Descargas.

Un enlace da "Cannot GET"

Lo que ves: al pulsar un enlace del menú, una página en blanco con Cannot GET /personajes.html.

Prueba esto

El href y el nombre del archivo no coinciden letra a letra, o el archivo todavía no existe o no está guardado. Copia el nombre del archivo desde VS Code (botón derecho → Copy Relative Path) y pégalo en el href.

El CSS no hace nada

Lo que ves: la página sale en blanco y negro, con la letra de siempre, como si no hubiera CSS.

Prueba esto (1): el enlace al CSS

Dentro del <head> de esa página tiene que estar <link rel="stylesheet" href="estilos.css">. Si una página tiene estilos y otra no, a la otra le falta esta línea.

Prueba esto (2): dónde está el archivo

estilos.css va al lado de index.html, no dentro de img. Y el nombre tiene que ser el mismo que en el href.

Funcionan las primeras reglas, pero las de debajo no

Lo que ves: el fondo cambia, pero el título no se pone del color que has escrito más abajo.

  • El título tendría que salir amarillo. Busca qué falta justo antes de h1 y ponlo.
Prueba esto

Busca la última regla que funciona: justo al final de ella falta un ; o una llave }. Mayús + Alt + F ordena el código y se ve mejor qué llave falta.

El botón no hace nada

Lo que ves: pulsas y no pasa nada. Lo primero, abre la consola (F12):

En la consolaQué pasa
En rojo: Cannot read properties of nullEl id del HTML y el del querySelector no coinciden, o falta la #.
En rojo: Unexpected token o Unexpected end of inputSobra o falta una llave o un paréntesis.

  • Lee el error de la consola. Compara el id del botón en el HTML con el del querySelector y arréglalo.

Una suma da 31 en lugar de 4

Lo que ves: los números se pegan uno detrás de otro en vez de sumarse.

  • Pulsa Sumar. Después pon Number() alrededor de cada .value y vuelve a pulsar.
Prueba esto

Lo que viene de una caja siempre es texto. Para sumar, conviértelo: Number(cajaA.value).

La web publicada no tiene mis cambios

Prueba esto (1): ¿lo habéis subido?

La web publicada solo cambia cuando subís a GitHub. Entrad en el repositorio y mirad arriba el último mensaje: tiene que ser el de hoy. Después, esperad un minuto y recargad con Ctrl + F5.

Prueba esto (2): en Live Server se ve y publicada no

Casi siempre son mayúsculas: en vuestro ordenador Logo.png y logo.png valen igual, pero en Internet no.

Mi pareja subió cambios y yo no los tengo

Prueba esto

Estás trabajando con una copia vieja. Baja la última versión de GitHub (<> Code → Download ZIP), extráela, borra la carpeta vieja y abre la nueva en VS Code, como al empezar cada taller (sesión 6). Nunca subas una carpeta que no hayas bajado hoy: borrarías el trabajo de tu pareja.

Si has probado todo y sigue sin funcionar, levanta la mano y enséñame la consola.
