Esta es BloqueCraft, la web de ejemplo de la pareja PixelRojo y CreeperVerde. Está hecha solo con HTML, con lo que habéis visto hasta la sesión 5. La vuestra tendrá las mismas piezas, pero con vuestro tema y vuestras palabras.

Recórrela y toca cada pieza

  1. Pasa por las 4 páginas con el menú de arriba: Inicio, Mobs, Biomas y Sobre esta web.
  2. Toca en la página cada cosa de la misión: la imagen, las dos listas, la tabla, el formulario y el enlace.
  3. Si no encuentras algo, pulsa Ver etiquetas: cada pieza sale marcada con su etiqueta.
  4. Pulsa Ver el código para ver cómo está escrita. Las líneas de lo último que has tocado salen en amarillo.

Lo que tiene que tener vuestra web

Como mínimo, esto. La última columna dice en qué sesión lo practicasteis.

QuéEn BloqueCraftSesión
4 páginas con el mismo menú: <nav> y <a>Todas4
Al menos 3 imágenes: <img>, cada una con su altInicio y Biomas3
Una lista ordenada: <ol>Inicio3
Una lista no ordenada: <ul>Mobs y Sobre esta web3
Una tabla: <table>Mobs4
Un formulario: <form>Biomas5
Un enlace a otra web: <a href="https://…">Mobs y Sobre esta web4

Para ver una página entera como la vería Chrome, pulsad Abrir en otra pestaña y después Ctrl + U: sale su código.

⚠️ No copiéis los textos de BloqueCraft. Lo que se copia es la forma: dónde va el menú, cómo se escribe una lista o una tabla. Lo de dentro es de vuestro tema.
