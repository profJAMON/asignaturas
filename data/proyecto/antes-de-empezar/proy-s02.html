Tres acciones de GitHub

GitHub será vuestra copia de seguridad. No vamos a enseñar comandos de Git: aprenderéis a crear el repositorio, subir archivos desde la web y descargar un ZIP para recuperar el trabajo.

  1. Cada alumno crea una cuenta con alias y correo del instituto.
  2. Una persona crea el repositorio de la pareja y añade a la otra como colaboradora.
  3. Subid los archivos arrastrándolos y comprobad que aparecen.
No subáis nombres reales, fotos personales, contraseñas ni datos del alumnado. El alias debe aparecer también en la página “Sobre esta web”.

Reto del día

  1. Prepara la portada con título, párrafo y una estructura ordenada.
  2. Sube el proyecto al repositorio.
  3. Descarga el ZIP y ábrelo en otra carpeta para comprobar que funciona.

Comprobación: la pareja puede señalar el repositorio, el botón de subida y el ZIP descargado.

Turnos

Apuntad quién sube hoy. En la próxima sesión subirá la otra persona. Antes de subir, guardad y revisad que ambos están trabajando con la copia más reciente.
