Todo es una caja

Para el navegador, cada elemento es una caja rectangular: un título, un párrafo, una imagen, una lista. Aunque no lo veas, cada caja tiene cuatro capas, de dentro hacia fuera:

El padding está dentro del borde; el margin, fuera.

CapaQué esEjemplo
ContenidoEl texto o la imagenwidth: 300px;
paddingEspacio entre el contenido y el borde. Se pinta con el color de fondo.padding: 20px;
borderLa línea que rodea la cajaborder: 2px solid orange;
marginEspacio por fuera, que separa la caja de las demás. Siempre transparente.margin: 20px;
💡 Pulsa F12, elige un elemento con Inspeccionar y baja hasta el final del panel de estilos: verás un dibujo de su caja con los números de su margin, border y padding.

Una tarjeta paso a paso

En Pixel Kart, cada piloto va en una tarjeta. El HTML agrupa todo lo de un piloto en un <div> con clase:

<div class="tarjeta">
    <img src="img/turbo-rex.png" alt="Turbo Rex, un dinosaurio verde en un kart rojo">
    <h3>Turbo Rex</h3>
    <p>El más rápido en las rectas, pero derrapa en las curvas.</p>
</div>

<div> es una caja vacía que no significa nada: sirve para agrupar cosas y darles estilo juntas.

.tarjeta {
    background-color: #2a2a55;
    padding: 16px;
    border: 2px solid #ffcc00;
    border-radius: 10px;
    margin-bottom: 20px;
    width: 250px;
}

.tarjeta img {
    width: 100%;
}
🦖

Turbo Rex

El más rápido en las rectas, pero derrapa en las curvas.

  • border lleva tres valores: grosor, estilo (solid, dashed, dotted) y color.
  • border-radius redondea las esquinas.
  • margin-bottom pone margen solo por abajo. También existen margin-top, margin-left y margin-right, y lo mismo con padding.
  • .tarjeta img significa "las imágenes que estén dentro de una tarjeta". width: 100% hace que la imagen ocupe todo el ancho de la tarjeta, y así nunca se sale.

Centrar una caja

Para que el contenido de la página no quede pegado a la izquierda en pantallas grandes, se le da un ancho máximo y margen automático a los lados:

main {
    max-width: 900px;
    margin: 0 auto;
    padding: 20px;
}

margin: 0 auto; significa "0 arriba y abajo, y automático a los lados": el navegador reparte el espacio sobrante a partes iguales y la caja queda centrada.

Bordes para la tabla

Ahora ya podemos arreglar la tabla de la sesión 5:

table {
    border-collapse: collapse;
}

th, td {
    border: 1px solid #ffcc00;
    padding: 8px 12px;
}

th, td con una coma aplica la regla a los dos a la vez. border-collapse: collapse junta los bordes de las celdas en una sola línea, en lugar de dos.

Antes de seguir

Quieres más espacio entre el texto y el borde de la tarjeta. ¿padding o margin?

padding: es el espacio de dentro, entre el contenido y el borde.

Quieres separar dos tarjetas entre sí. ¿padding o margin?

margin: es el espacio de fuera, entre una caja y las demás.

Escribes border: 2px orange; y no sale ningún borde. ¿Qué falta?

El estilo de la línea: border: 2px solid orange;.

Reto de hoy

  • El <main> de todas las páginas centrado, con max-width y margin: 0 auto.
  • Al menos 3 tarjetas (un <div> con clase) en alguna página, cada una con imagen, título y texto de vuestro tema.
  • Las tarjetas tienen fondo, padding, borde, esquinas redondeadas y separación entre ellas.
  • Las imágenes de las tarjetas no se salen de la tarjeta.
  • La tabla tiene bordes y espacio dentro de las celdas.
Pista 1: la imagen se sale de la tarjeta

Te falta la regla .tarjeta img { width: 100%; }, o la clase de tu tarjeta tiene otro nombre: el selector tiene que usar el mismo.

Pista 2: margin: 0 auto no centra nada

Una caja solo se puede centrar si es más estrecha que la página. Comprueba que tiene max-width o width.

Aplícalo en tu web

Usad lo que habéis aprendido en el resto de la web: separación entre apartados, un borde o un fondo para el formulario, espacio en el <header>... Las cajas bien separadas hacen que una web parezca mucho más cuidada.
