Todo es una caja

Para el navegador, cada etiqueta es una caja: un título, un párrafo, una lista. Cada caja tiene cuatro capas, de dentro hacia fuera:

El padding está dentro del borde; el margin, fuera.

CapaQué esEjemplo
paddingRelleno: espacio entre el texto y el borde. Se pinta con el color de fondo.padding: 15px;
borderLa línea que rodea la caja.border: 2px solid orange;
marginEspacio por fuera, que separa la caja de las demás. Siempre transparente.margin: 20px;

Relleno, borde y esquinas

.aviso {
    background-color: #fff3bf;
    padding: 15px;
    border: 2px solid orange;
    border-radius: 10px;
}

Hoy el circuito del volcán está cerrado.

  • border lleva tres valores, separados por espacios: grosor, tipo de línea (solid, dashed, dotted) y color.
  • border-radius redondea las esquinas. Cuanto más grande el número, más redondas.
🤔 Antes de seguir: escribes border: 2px orange; y no sale ningún borde. ¿Qué falta?

El tipo de línea: border: 2px solid orange;.

Ejercicio 1 — Avisos del instituto

Crea s09-ej1.html y s09-ej1.css, y conecta el CSS como en la sesión 8. Dentro del <body>:

<h1>Avisos</h1>
<p class="aviso">Mañana no hay clase de 8:00 a 9:00.</p>
<p class="aviso">La biblioteca cierra el viernes.</p>
  • ① Cada aviso: fondo #fff3bf, relleno de 15px, borde de 2px sólido naranja (orange) y esquinas de 10px.
  • ② Una sola regla .aviso en el CSS.
  • Toda la página, con la letra Arial, sans-serif.
Pista

Escribe una propiedad cada vez y guarda. Primero el fondo, después el padding, después el borde y al final las esquinas. Así ves qué cambia cada una.

Si lo has hecho bien: cambias el padding a 40px y los recuadros se hacen más altos, pero el texto no cambia de tamaño. Después, déjalo en 15px.

Tarjetas con <div>

<div> es una caja vacía que no se ve. Sirve para agrupar varias etiquetas y darles estilo juntas. Con una clase, se convierte en una tarjeta:

<div class="tarjeta">
    <h2>Turbo Rex</h2>
    <p>El más rápido en las rectas.</p>
</div>
.tarjeta {
    background-color: #2a2a55;
    width: 250px;
    margin: 20px auto;
    padding: 16px;
    border: 2px solid #ffcc00;
    border-radius: 10px;
}

Turbo Rex

El más rápido en las rectas.

  • width es el ancho de la caja. Sin él, la tarjeta ocupa todo el ancho de la página.
  • margin: 20px auto; quiere decir: 20px arriba y abajo, y automático a los lados. El navegador reparte el sitio que sobra a los dos lados y la caja queda centrada.
  • Para poner margen solo por un lado: margin-bottom (abajo), margin-top (arriba)… Igual con padding.

Truco de VS Code: la tarjeta en un segundo

En el HTML, escribe .tarjeta y pulsa Tab. VS Code escribe <div class="tarjeta"></div>. Pulsa Intro entre las dos etiquetas y escribe dentro. Funciona con cualquier nombre de clase: .aviso + Tab…

Ejercicio 2 — La tarjeta de un libro

Crea s09-ej2.html y s09-ej2.css, y conecta el CSS. Escribe la tarjeta con .tarjeta + Tab y copia dentro los textos de este HTML:

<div class="tarjeta">
    <h2>El faro perdido</h2>
    <p>Autora: Marta Sol</p>
    <p>Una niña descubre un faro que cambia de sitio cada noche.</p>
</div>
  • ① La tarjeta: fondo lightyellow, relleno de 20px, borde de 3px sólido #4361ee y esquinas de 15px.
  • ② El h2: color #4361ee.
  • ③ La tarjeta mide 300px de ancho y está centrada con margin: 30px auto;.
  • Toda la página, con la letra Georgia, serif.
Pista 1: la tarjeta ocupa todo el ancho

Te falta el width. Solo se puede centrar una caja más estrecha que la página.

Pista 2: la tarjeta no se centra

El valor del margin tiene dos partes: el número con px y la palabra auto, separados por un espacio.

Si lo has hecho bien: haces la ventana de Chrome más ancha y más estrecha, y la tarjeta sigue en el centro.

Cambiar al pasar el ratón: :hover

:hover es el estilo que tiene una etiqueta mientras el ratón está encima. Se escribe pegado al selector, sin espacio, en una regla aparte:

.boton {
    background-color: #2a2a55;
    color: white;
    padding: 10px 20px;
    border-radius: 8px;
    text-decoration: none;
}

.boton:hover {
    background-color: #ffcc00;
    color: #1b1b3a;
}

Sin el ratón: Jugar

Con el ratón encima: Jugar

  • En .boton:hover solo pones lo que cambia. Lo demás (el relleno, las esquinas) se queda como en .boton.
  • padding: 10px 20px; con dos números: 10px arriba y abajo, 20px a los lados.
  • text-decoration: none; quita el subrayado de los enlaces.
🤔 Antes de seguir: escribes .boton :hover, con un espacio. ¿Funciona?

No. Con el espacio significa otra cosa. Tiene que ir pegado: .boton:hover.

Ejercicio 3 — Los botones de un videojuego

Crea s09-ej3.html y s09-ej3.css, y conecta el CSS. Dentro del <body>:

<h1>Space Cats</h1>
<p>
    <a class="boton" href="#">Jugar</a>
    <a class="boton" href="#">Opciones</a>
    <a class="boton" href="#">Salir</a>
</p>

href="#" es un enlace que no lleva a ningún sitio: sirve para probar.

  • ① El h1: color #7209b7.
  • ② Los botones: fondo #7209b7, texto white, relleno 12px 25px, margen 5px, esquinas de 8px y sin subrayado.
  • ③ Con el ratón encima, el fondo del botón cambia a #f72585.
  • Toda la página: letra Arial, sans-serif y texto centrado.
Pista 1: los botones siguen subrayados

Busca en la explicación de arriba la propiedad que quita el subrayado. Va en la regla de .boton.

Pista 2: el ratón no cambia nada

Mira en F12 si tu regla .boton:hover aparece. Si no, revisa que el nombre de la clase sea igual que en el HTML y que :hover esté pegado.

Si lo has hecho bien: al pasar el ratón por cada botón, se vuelve rosa, y al quitarlo, vuelve a ser morado.

Bordes para las tablas

Las tablas que hiciste en HTML no tenían líneas. Con CSS se las pones:

table {
    border-collapse: collapse;
}

th, td {
    border: 1px solid #ffcc00;
    padding: 8px 12px;
}

tr:hover {
    background-color: #2a2a55;
}
PilotoPuntos
Turbo Rex25
Chispa18

Aquí, el ratón está encima de la fila de Turbo Rex.

  • th, td con una coma: la regla vale para los dos a la vez.
  • border-collapse: collapse; junta los bordes de las celdas en una sola línea. Sin él, salen líneas dobles.
  • tr:hover: la fila por la que pasa el ratón cambia de fondo. Así es más fácil leer una fila larga.
