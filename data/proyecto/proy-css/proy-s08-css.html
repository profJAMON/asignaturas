Qué es CSS

HTML dice qué hay en la página: un título, una lista, una imagen. CSS dice cómo se ve: de qué color, de qué tamaño, dónde se coloca.

El CSS se escribe en un archivo aparte, estilos.css, y todas las páginas lo usan. Así, si cambias un color en ese archivo, cambia en toda la web a la vez.

Conectar el CSS con las páginas

  1. En VS Code, crea el archivo estilos.css igual que creasteis index.html en la sesión 1: pasa el ratón sobre el nombre de la carpeta del proyecto → icono New File… → escribe estilos.css → Intro. Comprueba que queda al lado de index.html, no dentro de img.
  2. En cada página, añade esta línea dentro de <head>:
<head>
    <meta charset="UTF-8">
    <title>Pixel Kart</title>
    <link rel="stylesheet" href="estilos.css">
</head>

Para comprobar que funciona, escribe esto en estilos.css y guarda. Si el fondo de todas las páginas se vuelve amarillo, está bien conectado. Después bórralo.

body {
    background-color: yellow;
}

Cómo es una regla CSS

h1 {
    color: darkblue;
    font-size: 40px;
}
  • h1 es el selector: a qué elementos se aplica.
  • Entre llaves { } van las declaraciones.
  • Cada declaración es propiedad: valor;. Los dos puntos y el punto y coma son obligatorios.
⚠️ Si te olvidas un ; o una llave }, esa regla y a veces todas las que vienen detrás dejan de funcionar. Es el error más típico en CSS.

Cómo se escriben los colores

  • Por nombre, en inglés: red, white, darkblue, orange...
  • En hexadecimal: # y 6 caracteres, como #ff6b35. Hay millones. Para elegirlos, busca "color picker" en Google, o pulsa el cuadradito de color que VS Code muestra al lado de cada color en el CSS.
💡 Elige 2 o 3 colores para toda la web y no más. Y comprueba que el texto se lee bien sobre el fondo: texto claro sobre fondo oscuro, o al revés.

Selectores de etiqueta y de clase

Selector de etiqueta

Se aplica a todos los elementos de ese tipo, en todas las páginas:

body {
    background-color: #1b1b3a;
    color: white;
    font-family: Arial, sans-serif;
}

h1 {
    color: #ffcc00;
    text-align: center;
}

Selector de clase

¿Y si solo quieres cambiar algunos párrafos? Les pones una clase en el HTML, y en el CSS la llamas con un punto delante:

<p class="destacado">¡Nuevo circuito: Ciudad Neón!</p>
<p>El resto de párrafos se ven normales.</p>
.destacado {
    color: #ff6b35;
    font-size: 22px;
}

¡Nuevo circuito: Ciudad Neón!

El resto de párrafos se ven normales.

  • En HTML: class="destacado", sin punto.
  • En CSS: .destacado, con punto.
  • Una clase se puede usar en tantos elementos como quieras, de cualquier tipo.
  • Nombres de clase: minúsculas, sin espacios ni tildes, y que digan para qué son: destacado, aviso, tarjeta.

Comprueba tu CSS con F12

Chrome tiene una herramienta para ver qué CSS se le está aplicando a cada cosa de la página. Cuando algo no cambia como esperabas:

  1. En Chrome, pon el ratón encima de lo que no cambia (un título, por ejemplo) y pulsa el botón derecho → Inspeccionar.
  2. Se abre un panel (a la derecha o abajo) con dos partes. En una se ve el HTML de la página, con la etiqueta que has pulsado marcada en azul.
  3. En la otra parte, pestaña Styles (estilos), salen las reglas CSS que se aplican a esa etiqueta, con el nombre del archivo a la derecha (estilos.css:12 quiere decir línea 12).
  4. Busca la propiedad que no funciona:
    • Si no aparece, la regla no llega a ese elemento: el selector está mal escrito, la clase no coincide o la página no tiene el <link>.
    • Si aparece tachada, otra regla la está pisando.
    • Si tiene un triángulo amarillo ⚠, está mal escrita (por ejemplo, colr en lugar de color).
  5. Para cerrar el panel, pulsa F12 o la X de arriba a la derecha del panel.

Antes de seguir

¿Por qué el CSS va en un archivo aparte y no dentro de cada página?

Para que todas las páginas compartan el mismo aspecto y, cambiando un solo archivo, cambie toda la web.

Escribes .aviso { color: red; } y pones class=".aviso" en el HTML. No funciona. ¿Por qué?

En el HTML la clase va sin punto: class="aviso". El punto solo se pone en el CSS.

Cambias colores en estilos.css y una página no cambia. ¿Qué es lo más probable?

A esa página le falta la línea <link rel="stylesheet" href="estilos.css"> en el <head>.

Reto de hoy

  • Un único archivo estilos.css, conectado a todas las páginas.
  • Una paleta de 2 o 3 colores aplicada a body y a los títulos, con el texto fácil de leer.
  • Un tipo de letra (font-family) para toda la web.
  • Al menos una clase propia, con un nombre que diga para qué es, usada en 2 elementos o más.
  • Comprobación: al pasar de una página a otra con el menú, todas tienen el mismo aspecto.
Pista 1: no cambia nada en ninguna página

Comprueba que el archivo se llama exactamente estilos.css y que está en la misma carpeta que index.html, no dentro de img.

Pista 2: funcionan las primeras reglas y las de abajo no

Busca un ; o una } que falte justo antes de la primera regla que no funciona.

Aplícalo en tu web

Probad distintos colores hasta que la web tenga un aspecto que os guste y vaya con vuestro tema. Pedidle la opinión a otra pareja: ¿se lee bien?
