Hoy: le das color a tus páginas con CSS. Colores, fondos, tipos y tamaños de letra, y clases. Trabajas tú solo, en tu carpeta de ejercicios.

Qué es CSS

HTML dice qué hay en la página: un título, una lista, una imagen.

CSS dice cómo se ve: de qué color, de qué tamaño, dónde se coloca.

El CSS se escribe en un archivo aparte, que acaba en .css. La página HTML lo carga con una línea en el <head>.

Tus archivos de hoy

Desde hoy, cada ejercicio tiene dos archivos con el mismo nombre: el .html y su .css, uno al lado del otro.

ejercicios-pixelrojo/
├── s02-ej1.html
├── …
├── s08-ej1.html     ← el contenido
└── s08-ej1.css      ← los colores y la letra de s08-ej1.html
⚠️ Crea los dos archivos sueltos en tu carpeta de ejercicios, no dentro de img ni de otra carpeta.

Conectar el CSS con la página

Dentro del <head>, debajo del <title>, añade esta línea. En href va el nombre del archivo CSS:

<head>
    <meta charset="UTF-8">
    <title>Ejercicio 1</title>
    <link rel="stylesheet" href="s08-ej1.css">
</head>

Para escribirla rápido: escribe link y elige link:css en la lista. VS Code escribe la línea entera; solo cambias el nombre del archivo.

Cómo es una regla CSS

h1 {
    color: darkgreen;
}
  • h1 es el selector: a qué etiquetas se aplica. Aquí, a todos los <h1>.
  • Entre llaves { } van las órdenes.
  • Cada orden es propiedad: valor;. Los dos puntos y el punto y coma son obligatorios.
⚠️ Si te olvidas un ; o una llave }, esa regla y a veces todas las de debajo dejan de funcionar. Es el error más típico en CSS.

Crea s08-ej1.html (con ! + Tab) y s08-ej1.css. Dentro del <body>, escribe este HTML:

<p>Nos vemos los martes en la biblioteca.</p>

Después, en el .css, haz que se vea como en la imagen.

  • ① El h1 de color darkgreen.
  • El fondo de toda la página (body) de color lightyellow. Para el fondo se usa background-color.
  • ② En el <head>, el <link> a s08-ej1.css.
  • ③ El <title> es Ejercicio 1.
Pista 1: no cambia nada

Mira el href del <link>: tiene que ser exactamente el nombre de tu archivo CSS, letra a letra. Y guarda los dos archivos (Ctrl + S en cada pestaña).

Pista 2: el título cambia pero el fondo no

Escribe dos reglas separadas: una que empieza por body { y otra que empieza por h1 {. Cada una se cierra con su }.

Si lo has hecho bien: cambias darkgreen por red, guardas, y el título se vuelve rojo en Chrome sin tocar el HTML. Después, vuelve a dejarlo en darkgreen.

body {
    background-color: #1b1b3a;
    color: white;
    font-family: Arial, sans-serif;
}

h1 {
    color: #ffcc00;
    font-size: 40px;
    text-align: center;
}

Pixel Kart

El juego de karts más rápido del instituto.

  • Lo que pones en body vale para toda la página: el párrafo sale blanco y en Arial sin decir nada más.
  • Los colores se escriben en inglés (red, white, darkblue…) o en hexadecimal: # y 6 caracteres, como #ffcc00.
  • El tamaño se escribe con px pegado al número: 40px, no 40 px.
  • En font-family se ponen dos letras: la que quieres y otra de reserva (sans-serif) por si el ordenador no tiene la primera.

Truco de VS Code: que escriba él

  • Dentro de una regla, escribe solo ba: sale una lista con las propiedades que empiezan así. Baja con las flechas hasta background-color y pulsa Intro. Si la lista no sale, pulsa Ctrl + Espacio.
  • Después de los dos puntos, Ctrl + Espacio te enseña los valores posibles: center, left…
  • Al lado de cada color aparece un cuadradito de ese color. Pasa el ratón por encima: se abre una paleta para elegir el color con el ratón. VS Code escribe el código solo.

Selector de clase

Con p { … } cambian todos los párrafos. ¿Y si solo quieres cambiar algunos?

  1. En el HTML, les pones una clase: class="destacado".
  2. En el CSS, escribes el nombre de la clase con un punto delante: .destacado.
<p class="destacado">¡Nuevo circuito: Ciudad Neón!</p>
<p>El resto de párrafos se ven normales.</p>
.destacado {
    color: #ff6b35;
    font-size: 22px;
}

¡Nuevo circuito: Ciudad Neón!

El resto de párrafos se ven normales.

  • En HTML: class="destacado", sin punto. En CSS: .destacado, con punto.
  • Una clase se puede poner en muchas etiquetas, de cualquier tipo.
  • Nombres de clase: minúsculas, sin espacios ni tildes, y que digan para qué son: aviso, oferta, firma.
🤔 Antes de seguir: escribes .aviso { color: red; } y en el HTML pones class=".aviso". No funciona. ¿Por qué?

En el HTML la clase va sin punto: class="aviso". El punto solo se pone en el CSS.

Comprueba tu CSS con F12

Cuando algo no cambia como esperabas, Chrome te enseña qué CSS le llega:

  1. Pon el ratón encima de lo que no cambia, pulsa el botón derecho → Inspeccionar.
  2. Se abre un panel. En la pestaña Styles salen las reglas CSS de esa etiqueta, con el nombre del archivo y la línea (s08-ej3.css:12 es la línea 12).
  3. Busca la propiedad que falla:
    • Si no aparece, la regla no llega: el selector o la clase están mal escritos, o falta el <link>.
    • Si tiene un triángulo amarillo ⚠, está mal escrita (por ejemplo, colr en lugar de color).
  4. Para cerrar el panel, pulsa F12.
🤔 Antes de seguir: las dos primeras reglas de tu CSS funcionan y las de debajo no. ¿Qué es lo más probable?

Falta un ; o una } justo antes de la primera regla que no funciona.
