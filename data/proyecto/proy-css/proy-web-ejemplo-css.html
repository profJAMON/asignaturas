Esto no es una sesión: es lo mínimo que os pido en CSS, para que lo veáis hecho. Es la misma BloqueCraft del ejemplo de HTML, ahora con un único estilos.css. Vuestra web tiene que tener las mismas cosas, con vuestros colores y vuestro tema. Volved aquí siempre que no sepáis qué os falta.

Recórrela y toca cada cosa

  1. Pasa por las 4 páginas con el menú de arriba: Inicio, Mobs, Biomas y Sobre esta web.
  2. Pasa el ratón por el menú y por las tarjetas de Mobs: cambian de color.
  3. Toca en la página cada cosa de la misión: el título, el texto amarillo, una tarjeta y la tabla.
  4. Pulsa Ver el CSS para ver estilos.css. Las reglas de lo último que has tocado salen en amarillo.

Para ver una página entera como la vería Chrome, pulsad Abrir en otra pestaña. Con F12 → Elementos veis qué regla del CSS pinta cada cosa.

⚠️ No copiéis los colores de BloqueCraft. Lo que se copia es la forma: qué reglas hay y dónde van. Los colores y la letra son los de vuestro boceto.
