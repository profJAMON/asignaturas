Esto no es una sesión: es lo mínimo que os pido en CSS, para que lo veáis hecho. Es la misma BloqueCraft del ejemplo de HTML, ahora con un único estilos.css. Vuestra web tiene que tener las mismas cosas, con vuestros colores y vuestro tema. Volved aquí siempre que no sepáis qué os falta. Al final tenéis la chuleta con todo el CSS visto.

Recórrela y toca cada cosa

  1. Pasa por las 4 páginas con el menú de arriba: Inicio, Mobs, Biomas y Sobre esta web.
  2. Pasa el ratón por el menú y por las tarjetas de Mobs: cambian de color.
  3. Toca en la página cada cosa de la misión: el título, el texto amarillo, una tarjeta y la tabla.
  4. Pulsa Ver el CSS para ver estilos.css. Las reglas de lo último que has tocado salen en amarillo.

Conectar y escribir una regla

Lo visteis en la sesión 8.

Para…Se escribe
Conectar el CSS (en el <head> de cada página)<link rel="stylesheet" href="estilos.css">
Una reglah1 { color: gold; }: a quién, y entre llaves qué cambia. Cada línea acaba en ;
Un colorEn inglés (red, white) o con # y 6 caracteres (#ffcc00)
Un tamañoEl número con px pegado: 22px

Colores y letra

Lo visteis en la sesión 8. Lo que va en body vale para toda la página.

Para…Se escribe
Color del textocolor: white;
Color del fondobackground-color: #1b1b3a;
Tipo de letra (y otra de reserva)font-family: Arial, sans-serif;
Tamaño de la letrafont-size: 22px;
Centrar el textotext-align: center; (o left, right)

A quién se aplica: selectores

Lo visteis en las sesiones 8, 9b y 10b.

Para…Se escribe
Todas las etiquetas de un tipop { … }
Solo algunas: una claseEn el HTML class="destacado" (sin punto). En el CSS .destacado { … } (con punto)
Dos a la vezth, td { … } (con coma)
Solo las que están dentro de otranav a { … } .tarjeta h2 { … } (con espacio)
Cuando el ratón está encima.boton:hover { … } (pegado, sin espacio). Solo lo que cambia

Cajas y tarjetas

Lo visteis en la sesión 9a (el subrayado, en la 9b). Para una tarjeta: un <div class="tarjeta"> con todo dentro.

Para…Se escribe
Relleno: espacio entre el texto y el bordepadding: 15px; (10px 20px: arriba y abajo, y a los lados)
El borde: grosor, tipo y colorborder: 2px solid orange; (o dashed, dotted)
Esquinas redondeadasborder-radius: 10px;
Espacio por fuera, entre cajasmargin: 20px; (solo abajo: margin-bottom)
El anchowidth: 250px;
Centrar una cajamargin: 20px auto; (necesita width)
Quitar el subrayado de un enlacetext-decoration: none;

Tablas

Lo visteis en la sesión 9b.

Para…Se escribe
Bordes en las celdasth, td { border: 1px solid #ffcc00; }

Espacio dentro de las celdaspadding: 8px 12px;
Que la fila cambie con el ratóntr:hover { background-color: #2a2a55; }

En fila: Flexbox

Lo visteis en las sesiones 10a y 10b. Todo esto va en la caja que contiene a las demás (nav, .tarjetas), no en cada caja.

Para…Se escribe
Ponerlas en filadisplay: flex;
Hueco entre ellasgap: 20px;
Si no caben, a la línea de abajoflex-wrap: wrap;
Juntarlas en el centrojustify-content: center;
Una en cada puntajustify-content: space-between;
Centradas en verticalalign-items: center;
