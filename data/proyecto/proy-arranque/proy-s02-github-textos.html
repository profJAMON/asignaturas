En pareja: vuestra web en GitHub

Los ordenadores del aula se actualizan, se estropean y a veces se formatean. Si vuestra web solo está en un ordenador, un día podéis llegar a clase y no tener nada. Por eso la guardáis también en GitHub, una web donde los programadores guardan su código: es como un Google Drive para programadores.

Ya tenéis la cuenta de GitHub de la pareja, y os he creado un repositorio: la carpeta de vuestra web guardada en GitHub. Más adelante, desde ahí se publicará vuestra web en Internet.

Subís al acabar cada taller y descargáis cuando lo necesitáis.

Entrar en vuestro repositorio

  1. En Chrome, entra en github.com y pulsa Sign in (arriba a la derecha).
  2. Escribe el usuario y la contraseña de la cuenta de la pareja y pulsa Sign in.
  3. En la columna de la izquierda, en Top repositories, aparece vuestro repositorio. Púlsalo.
  4. Guárdalo en marcadores: pulsa la estrella ☆ de la derecha de la barra de direcciones. Así lo encontraréis rápido cada semana.
Si al entrar sale un aviso de invitación ("… has invited you to join …"), pulsad el botón verde Join o Accept. Si no veis el repositorio en ningún sitio, avisadme.
GitHub está en inglés. No hace falta que lo entiendas todo: aquí tienes el nombre exacto de cada botón que tienes que pulsar.

Subir los archivos

Primero, colocad Chrome y la carpeta de vuestra web lado a lado:

  1. Con el repositorio abierto en Chrome, pulsa a la vez Windows + ←. Chrome se pega a la mitad izquierda.
  2. Abre el Explorador de archivos (Windows + E) y ve a Documentos → la carpeta de vuestra web.
  3. Pulsa Windows + →. El Explorador se pega a la mitad derecha.

Ahora, abrid la zona de subida:

Go to file Add file ▾ + Create new file⤒ Upload files <> Code ▾

Así se ven los botones en GitHub. Pulsa Add file y después Upload files.

  1. Pulsa Add file → Upload files. Aparece una zona grande que dice "Drag files here…" (arrastra aquí los archivos).
  2. En el Explorador, entra dentro de la carpeta de vuestra web: tienes que ver index.html y la carpeta img.
  3. Pulsa en un espacio en blanco y después Ctrl + A: se selecciona todo.
  4. Arrastra lo seleccionado hasta la zona de subida de Chrome y suelta. Debajo aparece la lista de archivos: comprueba que está index.html.
La primera vez el repositorio está vacío y no hay botón Add file. En su lugar hay una frase con un enlace azul: uploading an existing file. Púlsalo: lleva a la misma zona de subida.
⚠️ Arrastra lo que hay dentro de la carpeta, no la carpeta entera. Si arrastras la carpeta, en GitHub todo queda metido dentro de otra carpeta y la web no se podrá publicar.
💡 Una carpeta vacía (como img si aún no tiene imágenes) no se sube: GitHub solo guarda archivos. Es normal. Se subirá sola cuando tenga algo dentro.

Descargar los archivos

Esto solo lo haréis cuando un ordenador pierda vuestro trabajo o tengáis que cambiar de ordenador. Hoy lo probáis una vez para saber hacerlo:

  1. En el repositorio, pulsa el botón verde <> Code → Download ZIP.
  2. Abre la carpeta Descargas: está el zip, acabado en -main.zip.
  3. Botón derecho sobre el zip → Extraer todo… → Extraer. Se crea una carpeta normal. Ábrela: dentro está vuestro index.html.
  4. Como hoy era solo una prueba, borra el zip y la carpeta extraída de Descargas.

Tres cosas que tenéis que saber

  • Solo sube uno, desde el ordenador donde habéis trabajado ese día. Si subís un archivo que ya estaba, el nuevo sustituye al antiguo: si alguien sube una versión vieja, se pierde el trabajo nuevo.
  • En los talleres, cada semana sube uno de los dos. Decididlo ahora: quién sube en el primer taller (sesión 6).
  • GitHub guarda todas las versiones. Si un día estropeáis algo, avisadme: se puede recuperar.

VS Code: lo básico

Abrir tu carpeta

  1. Abre VS Code. Si ya tiene otra carpeta abierta, menú File → Close Folder.
  2. Menú File → Open Folder… → Documentos → pulsa una vez sobre tu carpeta de ejercicios → Seleccionar carpeta.
  3. Si pregunta "Do you trust the authors…?", pulsa Yes, I trust the authors.

Crear un archivo

  1. Pasa el ratón por encima del nombre de tu carpeta, en el panel de la izquierda (Explorer).
  2. Pulsa el icono New File… (una hoja con un +).
  3. Escribe el nombre con su extensión, por ejemplo s02-ej1.html, y pulsa Intro.

Los nombres de los ejercicios siempre siguen la misma regla: s + número de sesión + -ej + número de ejercicio. Así los encuentras y los corrijo rápido.

La estructura en un segundo: ! + Tab

En la sesión 1 copiaste la estructura mínima letra a letra. VS Code la escribe por ti:

  1. En el archivo vacío, escribe solo un signo de exclamación: !
  2. Aparece una lista pequeña con Emmet Abbreviation. Pulsa Tab (o Intro).
  3. VS Code escribe esto:
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>

</body>
</html>

Cambia siempre dos cosas: lang="en" por lang="es" (la página está en castellano) y Document por el título de tu página. La línea viewport sirve para que la página se vea bien en el móvil: déjala.

Etiquetas sin escribir los < >

Dentro de <body>, escribe h1 y pulsa Tab. VS Code escribe <h1></h1> y deja el cursor en medio, listo para escribir el texto. Funciona con cualquier etiqueta: p + Tab, h2 + Tab…

Y si escribes tú la etiqueta de apertura, <p>, VS Code añade sola la de cierre, </p>.

Títulos y párrafos

HTML tiene 6 niveles de título, de <h1> (el más importante) a <h6>. El texto normal va en párrafos, <p>:

<h1>Pixel Kart</h1>
<h2>Modos de juego</h2>
<h3>Carrera rápida</h3>
<p>Una sola carrera contra la máquina.</p>
<h3>Campeonato</h3>
<p>Cuatro carreras seguidas.</p>

Pixel Kart

Modos de juego

Carrera rápida

Una sola carrera contra la máquina.

Campeonato

Cuatro carreras seguidas.

  • Solo hay un <h1> por página: el título principal.
  • Los títulos se eligen por importancia, no por tamaño: un <h3> es un apartado dentro de un <h2>. El tamaño lo cambiaremos con CSS.
  • El navegador ignora los saltos de línea del código. Cada párrafo va en su propio <p>.

Comentarios

Un comentario es una nota para quien lee el código. No se ve en la página. Sirve para marcar dónde empieza cada parte:

<!-- Modos de juego -->
<h2>Modos de juego</h2>

Para escribirlo rápido: escribe el texto en una línea, déjate el cursor en ella y pulsa Ctrl + /. VS Code le pone el <!-- y el -->.

🤔 Antes de seguir: quieres que "Pabellón" y "Jueves a las 17:00" salgan en dos líneas, pero dentro del mismo párrafo. ¿Qué usas?

<br> entre los dos textos. Si los pones en dos <p>, son dos párrafos, con más espacio entre ellos.

Entregar tus ejercicios en Classroom

Al final de cada sesión de ejercicios, entregas tu carpeta entera comprimida en un zip. Además, así tienes una copia de seguridad de tus ejercicios.

  1. En VS Code, comprueba que no queda ninguna pestaña con el punto blanco de "sin guardar".
  2. En el Explorador, ve a Documentos. Pulsa con el botón derecho sobre tu carpeta de ejercicios:
    • Windows 11: Comprimir en → Archivo ZIP (en algunos ordenadores sale directamente Comprimir en archivo ZIP).
    • Windows 10: Enviar a → Carpeta comprimida (en zip).
    Aparece al lado un archivo con el mismo nombre, acabado en .zip. Si Windows pregunta si quieres reemplazar el de la semana pasada, di que sí.
  3. En Chrome, entra en classroom.google.com con tu cuenta del instituto → la clase de Proyecto → la tarea que te diga.
  4. Pulsa + Añadir o crear → Archivo → Examinar. Ve a Documentos, elige el .zip y pulsa Subir.
  5. Pulsa Entregar.
Entregas lo que tengas hecho, aunque no hayas acabado. Lo que te falte lo acabas la semana que viene y vuelves a entregar el zip.
