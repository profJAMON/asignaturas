Qué es una web

Una página web es un archivo de texto con instrucciones que el navegador (Chrome, por ejemplo) sabe leer y convertir en lo que ves en pantalla. Una web completa es una carpeta con varios de esos archivos:

  • Archivos .html: el contenido (textos, imágenes, enlaces).
  • Un archivo .css: el aspecto (colores, tamaños, posición).
  • Un archivo .js: lo que se mueve o reacciona (botones, cálculos).
  • Una carpeta img: las imágenes.

Durante el curso os enseñaré una web de ejemplo que iré construyendo en cada sesión: Pixel Kart, un videojuego de carreras inventado. Vosotros haréis lo mismo, pero con vuestro propio tema.

🤔 Haz la prueba: en cualquier web, pulsa Ctrl+U. Lo que ves es su código HTML. Todas las webs del mundo están hechas de texto como ese.

Privacidad: nada de datos personales

La web va a estar publicada en Internet, así que cualquiera podrá verla. Por eso:

  • Usa siempre tu alias, nunca tu nombre ni tus apellidos.
  • Nada de fotos vuestras, de vuestra casa, del instituto ni de amigos.
  • Nada de teléfonos, direcciones, correos personales ni la ciudad donde vives.
Un buen alias no se parece a tu nombre real: RayoAzul sí, MarcosG2009 no.

Tu carpeta de proyecto

Todo el curso vais a trabajar dentro de una sola carpeta. Creadla ahora en el ordenador de la pareja:

  1. Abre el Explorador de archivos y ve a Documentos.
  2. Crea una carpeta con el nombre de vuestro tema, en minúsculas, sin espacios ni tildes. Por ejemplo: pixel-kart.
  3. Dentro, crea otra carpeta llamada img.
⚠️ Nombres de archivos y carpetas: minúsculas, sin espacios, sin tildes, sin ñ. Usa guiones si necesitas separar palabras. Un espacio o una tilde en un nombre es la causa número uno de "¡no me sale la imagen!".

VS Code y Live Server

VS Code es el programa donde escribiremos el código. Live Server es una extensión de VS Code que abre tu web en Chrome y la recarga sola cada vez que guardas.

  1. Abre VS Code.
  2. Menú Archivo → Abrir carpeta y elige la carpeta de vuestro proyecto.
  3. En el panel de la izquierda, pulsa el icono de nuevo archivo y llámalo index.html.

index.html es un nombre especial: es la página de inicio. Cuando alguien visite vuestra web, es la primera que verá.

La estructura mínima de una página

Copia esto en index.html:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Pixel Kart</title>
</head>
<body>
    <h1>Pixel Kart</h1>
    <p>El juego de karts más rápido del instituto.</p>
</body>
</html>
  • Todo lo que va entre < y > es una etiqueta. Casi todas se abren (<p>) y se cierran (</p>).
  • <head> tiene información sobre la página que no se ve dentro de ella. Por ejemplo, <title> es el texto de la pestaña.
  • <body> es lo que se ve en la página.
  • <h1> es el título principal y <p> es un párrafo.

Ábrela con Live Server

  1. Guarda el archivo con Ctrl+S.
  2. Pulsa con el botón derecho dentro del código y elige Open with Live Server (o pulsa Go Live abajo a la derecha).
  3. Se abrirá Chrome con tu página. Cambia el texto del párrafo, guarda y mira cómo se actualiza sola.
💡 Si al guardar no cambia nada, casi siempre es porque no has guardado. En VS Code, un punto blanco en la pestaña del archivo significa "hay cambios sin guardar".

Antes de seguir

¿Qué diferencia hay entre lo que va en <head> y lo que va en <body>?

<head> tiene información sobre la página (como el título de la pestaña), que no se ve dentro de ella. <body> es el contenido que se ve.

¿Por qué la página de inicio se tiene que llamar index.html?

Porque es el nombre que buscan los servidores web cuando alguien entra en la dirección de una web. Si no existe, el visitante no ve la portada.

¿Por qué no puede haber espacios ni tildes en los nombres de archivo?

Porque en las direcciones web los espacios y las tildes se convierten en códigos raros, y es fácil que una ruta deje de funcionar, sobre todo al publicar la web.
