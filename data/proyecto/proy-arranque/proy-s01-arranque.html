Qué es una web

Una página web es un archivo de texto con instrucciones que el navegador (Chrome, por ejemplo) sabe leer y convertir en lo que ves en pantalla. Una web completa es una carpeta con varios de esos archivos:

  • Archivos .html: el contenido (textos, imágenes, enlaces).
  • Un archivo .css: el aspecto (colores, tamaños, posición).
  • Un archivo .js: lo que se mueve o reacciona (botones, cálculos).
  • Una carpeta img: las imágenes.

Durante el curso os enseñaré una web de ejemplo que iré construyendo en cada sesión: Pixel Kart, un videojuego de carreras inventado. Vosotros haréis lo mismo, pero con vuestro propio tema.

🤔 Haz la prueba: en cualquier web, pulsa Ctrl+U. Lo que ves es su código HTML. Todas las webs del mundo están hechas de texto como ese.

Privacidad: nada de datos personales

La web va a estar publicada en Internet, así que cualquiera podrá verla. Por eso:

  • Usa siempre tu alias, nunca tu nombre ni tus apellidos.
  • Nada de fotos vuestras, de vuestra casa, del instituto ni de amigos.
  • Nada de teléfonos, direcciones, correos personales ni la ciudad donde vives.

Tu carpeta de proyecto

Todo el curso vais a trabajar dentro de una sola carpeta. Creadla ahora en el ordenador de la pareja:

  1. Abre el Explorador de archivos: es el icono de la carpeta amarilla de la barra de abajo. También se abre pulsando a la vez Windows + E.
  2. En la columna de la izquierda, pulsa Documentos.
  3. Pulsa con el botón derecho en un espacio en blanco de la ventana → Nuevo → Carpeta. Aparece una carpeta llamada "Nueva carpeta" con el nombre en azul.
  4. Sin pulsar nada más, escribe el nombre de vuestro tema en minúsculas, sin espacios ni tildes (por ejemplo, pixel-kart) y pulsa Intro.
  5. Haz doble clic en la carpeta para entrar en ella. Arriba, en la barra de dirección, tiene que poner Documentos › pixel-kart.
  6. Dentro, repite el paso 3 y llama a la nueva carpeta img. Aquí guardaréis las imágenes.

Así tiene que quedar:

Documentos/
└── pixel-kart/
    └── img/
¿Te has equivocado con el nombre? Botón derecho sobre la carpeta → Cambiar nombre (en Windows 11 es un icono de un cuadro con una barra, arriba del menú), escribe el nombre bueno e Intro.
⚠️ Nombres de archivos y carpetas: minúsculas, sin espacios, sin tildes, sin ñ. Usa guiones si necesitas separar palabras. Un espacio o una tilde en un nombre es la causa número uno de "¡no me sale la imagen!".

VS Code y Live Server

VS Code es el programa donde escribiremos el código. Live Server es una extensión de VS Code que abre tu web en Chrome y la recarga sola cada vez que guardas.

Abrir la carpeta en VS Code

  1. Pulsa la tecla Windows, escribe code y pulsa en Visual Studio Code (el icono es una especie de cinta azul).
  2. Si sale una pestaña de bienvenida (Welcome), ciérrala con la X de la pestaña.
  3. Arriba a la izquierda, pulsa el menú File (o Archivo) → Open Folder… (Abrir carpeta…).
  4. Se abre una ventana como la del Explorador. Ve a Documentos, pulsa una vez sobre la carpeta de vuestro proyecto y pulsa el botón Seleccionar carpeta.
  5. Si VS Code pregunta "Do you trust the authors of the files in this folder?" (¿confías en los autores de estos archivos?), pulsa Yes, I trust the authors. Los autores sois vosotros.
  6. A la izquierda aparece el panel Explorer con el nombre de vuestra carpeta en mayúsculas y, dentro, la carpeta img.

Crear el archivo index.html

  1. Pasa el ratón por encima del nombre de la carpeta en el panel de la izquierda. Aparecen unos iconos pequeños.
  2. Pulsa el primero, New File… (una hoja con un +).
  3. Escribe index.html y pulsa Intro. Comprueba que no se ha creado dentro de img: tiene que estar al mismo nivel que la carpeta img.
  4. El archivo se abre en el centro, vacío, listo para escribir.
💡 Si lo has creado dentro de img por error, arrástralo con el ratón en el panel de la izquierda hasta el nombre de la carpeta principal.

index.html es un nombre especial: es la página de inicio. Cuando alguien visite vuestra web, es la primera que verá.

La estructura mínima de una página

Copia esto en index.html:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Pixel Kart</title>
</head>
<body>
    <h1>Pixel Kart</h1>
    <p>El juego de karts más rápido del instituto.</p>
</body>
</html>
  • Todo lo que va entre < y > es una etiqueta. Casi todas se abren (<p>) y se cierran (</p>).
  • <head> tiene información sobre la página que no se ve dentro de ella. Por ejemplo, <title> es el texto de la pestaña.
  • <body> es lo que se ve en la página.
  • <h1> es el título principal y <p> es un párrafo.

El juego de karts más rápido del instituto.

Ábrela con Live Server

  1. Guarda el archivo: pulsa a la vez Ctrl + S.
  2. Mira abajo del todo a la derecha, en la barra azul de VS Code: hay un botón que dice Go Live. Púlsalo.
  3. Se abre Chrome con vuestra página. Arriba, la dirección empieza por 127.0.0.1:5500: significa que la web se está viendo desde vuestro ordenador, todavía no está en Internet.
  4. Coloca Chrome y VS Code lado a lado: pulsa Windows + ← en uno y Windows + → en el otro.
  5. Cambia el texto del párrafo en VS Code y guarda con Ctrl + S. Mira Chrome: se actualiza solo.
Si no ves el botón Go Live, pulsa con el botón derecho dentro del código y elige Open with Live Server. Si tampoco aparece, la extensión no está instalada en ese ordenador: avísame.
Al acabar la clase, pulsa otra vez en la barra azul donde ahora pone Port: 5500 para parar Live Server.
💡 Si al guardar no cambia nada, casi siempre es porque no has guardado. En VS Code, un punto blanco en la pestaña del archivo significa "hay cambios sin guardar".

Antes de seguir

¿Qué diferencia hay entre lo que va en <head> y lo que va en <body>?

<head> tiene información sobre la página (como el título de la pestaña), que no se ve dentro de ella. <body> es el contenido que se ve.

¿Por qué la página de inicio se tiene que llamar index.html?

Porque es el nombre que buscan los servidores web cuando alguien entra en la dirección de una web. Si no existe, el visitante no ve la portada.

¿Por qué no puede haber espacios ni tildes en los nombres de archivo?

Porque en las direcciones web los espacios y las tildes se convierten en códigos raros, y es fácil que una ruta deje de funcionar, sobre todo al publicar la web.

Antes de irte

Hoy todavía no tenemos GitHub (lo creamos la semana que viene), así que guardad una copia de la carpeta del proyecto en el Google Drive del instituto de uno de los dos. Si el ordenador falla esta semana, no perderéis nada.

  1. En VS Code, comprueba que está todo guardado: ninguna pestaña con un punto blanco.
  2. En Chrome, abre una pestaña nueva y entra en drive.google.com. Si te pide entrar, usa tu cuenta del instituto.
  3. Arriba a la izquierda, pulsa el botón + Nuevo → Subir carpeta.
  4. Se abre una ventana: ve a Documentos, pulsa una vez sobre la carpeta del proyecto y pulsa Subir. Si Chrome pregunta si quieres subir los archivos, pulsa Subir otra vez.
  5. Abajo a la derecha sale un recuadro con la subida. Espera a que salga una marca verde ✓.
  6. Comprueba que en Mi unidad aparece la carpeta con el nombre de vuestro proyecto.
Si la semana que viene el ordenador ha perdido la carpeta: entra en Drive, botón derecho sobre la carpeta → Descargar. Se descarga un zip en Descargas: botón derecho → Extraer todo… y mueve la carpeta a Documentos.
