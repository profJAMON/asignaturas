Del ordenador a tu pantalla

Al subir los archivos, GitHub guarda una copia. Cloudflare Pages puede servir esos archivos cuando alguien visita la dirección publicada. DNS relaciona el nombre con el servidor y el navegador solicita, recibe y dibuja la página.

Ordenador → GitHub → Cloudflare Pages (servidor) → DNS → navegador

Reto del día

  1. Publica el repositorio de prueba desde la cuenta del docente.
  2. Abre la dirección publicada y cambia un párrafo.
  3. Sube el cambio y observa que la publicación se actualiza.
  4. Empieza la página “Cómo llega mi web a tu pantalla” con un esquema y palabras propias.

Comprobación: puedes explicar qué copia guarda GitHub, qué sirve Cloudflare y para qué interviene DNS.
