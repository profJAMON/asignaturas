Una web son varias páginas conectadas

Un enlace usa <a href="...">. Un menú repetido en todas las páginas permite orientarse y volver atrás.

<nav>
  <a href="index.html">Inicio</a>
  <a href="contenido.html">Contenido</a>
  <a href="sobre.html">Sobre esta web</a>
</nav>

Reto del día

  1. Crea tres archivos HTML con títulos distintos.
  2. Copia el mismo menú en los tres.
  3. Comprueba todos los enlaces empezando desde cada página.

Comprobación: desde cualquier página llegas a las otras dos sin escribir una dirección a mano.

Aplícalo en tu web

Usad tres páginas con nombres claros. Reservad una para “Sobre esta web” y otra para “Cómo llega mi web a tu pantalla”.
