Prueba individual

Durante la primera hora cada persona trabaja sobre una copia de la web de su pareja, sin Internet. Recibirás una tarjeta con cuatro o cinco cambios pequeños.

Tipos de cambio

  • Añadir una fila a la tabla.
  • Cambiar el color del menú desde CSS.
  • Modificar el texto que muestra un botón.
  • Añadir una condición if/else.
  • Corregir una ruta o un selector.

Lee el encargo, localiza primero el HTML, CSS o JavaScript afectado, haz un cambio y comprueba el resultado. No copies una solución sin entenderla.

Preparar la presentación

Cada miembro explicará una parte distinta y responderá preguntas sobre el código y sobre el recorrido ordenador → GitHub → Cloudflare → DNS → navegador.
