Presentación

Enseñad el resultado y recorred las tres páginas. La expresión oral no es el objetivo principal: se valora que cada persona entienda lo que ha hecho.

Preguntas individuales posibles

  • ¿Qué ocurre si borras esta línea?
  • ¿Dónde cambiarías el color del menú?
  • ¿Qué selector busca ese código?
  • ¿Qué hace value o classList.toggle?
  • ¿Qué diferencia hay entre GitHub y Cloudflare?

Entrega

Haced el último envío a GitHub, comprobad la dirección publicada y verificad que no quedan datos reales, rutas rotas ni cambios sin guardar.

Comprobación: cada miembro responde preguntas diferentes sin que la otra persona le dicte la respuesta.
