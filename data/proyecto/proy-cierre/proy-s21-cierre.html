Última sesión

Hoy es la última sesión del módulo. La usamos para dos cosas:

  • Quien lo necesite repite la prueba o la presentación: si faltaste ese día o te lo he dicho yo. Si crees que es tu caso y no te he avisado, pregúntamelo al empezar la clase.
  • El resto hace un cierre del curso con las actividades de abajo.

Lo que habéis aprendido

En septiembre la mayoría no había escrito nunca una línea de código. Ahora tenéis una web publicada, hecha a mano, con:

LenguajeLo que sabéis hacer
HTMLPáginas con títulos, textos, imágenes, enlaces, menús, listas, tablas y formularios.
CSSColores, tipos de letra, cajas con bordes y espacios, y colocar cosas en fila con Flexbox.
JavaScriptVariables, botones que reaccionan, leer formularios, tomar decisiones con if, cambiar el aspecto y repetir con bucles.
PublicaciónGuardar el trabajo en GitHub, publicar una web y entender cómo llega hasta la pantalla de quien la visita.

Esto es la base de cualquier web del mundo. Las webs grandes usan más herramientas, pero por debajo siguen siendo HTML, CSS y JavaScript.

Actividades de cierre

Visita las webs de los demás

Os pasaré las direcciones de todas las webs de la clase. Visitadlas en el móvil y buscad:

  • Una cosa de otra web que os guste y que no se os había ocurrido.
  • Un truco de código que usan y vosotros no. Abrid el código con Ctrl+U para ver cómo lo han hecho.
  • Algún error (una imagen que no carga, un enlace roto...) y decídselo a esa pareja.

Guardad vuestra web

La web publicada la retiraré cuando acabe el curso, pero el código es vuestro:

  • Cada uno descarga el zip de vuestro repositorio: en GitHub, botón verde <> Code → Download ZIP.
  • Lo sube a su Google Drive del instituto: entra en drive.google.com → botón + Nuevo → Subir archivo → en Descargas, elige el zip → Abrir. Espera a la marca verde ✓.
  • Si queréis seguir con la web por vuestra cuenta, cualquier ordenador con VS Code os sirve: solo tenéis que abrir la carpeta.
