Cómo son las presentaciones

Hoy cada pareja presenta su web al resto de la clase. Cada presentación dura unos 15-20 minutos en total:

  1. Recorrido por la web (3-4 minutos): la abrís en el proyector, en la dirección publicada, y enseñáis las páginas y lo que funciona con JavaScript. Hablan los dos.
  2. Preguntas sobre el código: abrís VS Code y os hago preguntas a cada uno por separado, distintas para cada uno, sobre vuestro código y sobre la página "Cómo llega mi web a tu pantalla".
La nota de la presentación es individual (20 %). No cuenta si hablas bien en público o si estás nervioso: cuenta si entiendes el código de tu web y sabes explicar qué hace.

Qué tipo de preguntas os haré

TipoEjemplo
Qué hace"¿Qué hace esta línea?", "¿Para qué sirve esta clase?"
Qué pasaría"¿Qué pasa si borro el Number()?", "¿Y si quito el display: flex?"
Dónde"¿Dónde cambiarías el color del menú?", "¿En qué archivo está el código del botón?"
Cómo llega"¿Qué hace el DNS?", "¿Qué pasa cuando subís un archivo a GitHub?"

Si no sabes una respuesta, puedes buscarla en vuestro código mientras piensas en voz alta. Eso también cuenta: demuestra que sabes dónde mirar.

Mientras presentan los demás

  • Escuchad y fijaos en qué han hecho distinto a vosotros.
  • Al final de cada presentación, podéis hacer una pregunta o decir algo que os haya gustado de su web.

Entrega final

La versión que está en GitHub al empezar la clase de hoy es la que evalúo como web final (20 %). Después de presentar no se pueden hacer más cambios.

  • Todo subido a GitHub antes de empezar la clase.
  • La web publicada se ve bien y sin errores en la consola.
  • Tenéis a mano la dirección de la web y la carpeta abierta en VS Code para enseñar el código.
