Un archivo JS por página

Cada página que necesite JavaScript tiene su propio .js, con el mismo nombre. Así es la carpeta de Pixel Kart:

pixel-kart/
├── index.html
├── index.js        ← modo oscuro de la portada
├── personajes.html
├── personajes.js   ← mostrar y ocultar los trucos
├── circuitos.html  (no tiene JS)
├── torneo.html
├── torneo.js       ← el formulario de inscripción
├── estilos.css
└── img/

Y cada página conecta solo el suyo, justo antes de </body>: torneo.html lleva <script src="torneo.js"></script>.

⚠️ ¿Por qué no un solo .js para todas? Porque si index.html carga el código del torneo, querySelector("#boton-inscribir") no encuentra nada en la portada y sale el error Cannot read properties of null. Con un archivo por página, cada código solo busca lo que su página tiene.

Lo que tiene que quedar hoy en vuestra web

El formulario funciona

  • El formulario de la sesión 6 tiene un id en cada caja y en el botón, y el botón lleva type="button".
  • Debajo del formulario hay un párrafo vacío con id para la respuesta.
  • Al pulsar el botón se leen al menos 2 campos con value y sale un mensaje que usa lo escrito. Lo viste en el ejercicio 5 de la sesión 14.
  • Si algún campo es un número, se convierte con Number() antes de calcular.
  • La respuesta cambia según lo que escribe o elige el usuario, con un if. Lo viste en los ejercicios 2 y 3 de la sesión 15.

Y en todas las páginas

  • Cada página con JavaScript tiene su .js con el mismo nombre, conectado justo antes de </body>.
  • En cada .js, un comentario encima de cada paso (// 1. Buscar…).
  • Abrís todas las páginas con la consola abierta y pulsáis todos los botones: ningún error en rojo.

Ejemplo: el torneo de Pixel Kart

// 1. Buscar los elementos
let cajaAlias = document.querySelector("#alias");
let cajaEdad = document.querySelector("#edad");
let cajaPiloto = document.querySelector("#piloto");
let boton = document.querySelector("#boton-inscribir");
let mensaje = document.querySelector("#mensaje");

// 2. Esperar al clic
boton.addEventListener("click", function () {
    // 3. Leer las cajas y responder según la edad
    let alias = cajaAlias.value;
    let edad = Number(cajaEdad.value);
    let piloto = cajaPiloto.value;

    if (edad >= 12) {
        mensaje.textContent = "¡Inscrito, " + alias + "! Correrás con " + piloto + ".";
    } else {
        mensaje.textContent = "Lo siento, " + alias + ": hay que tener 12 años o más.";
    }
});

¡Inscrito, RayoAzul! Correrás con Chispa.

Errores típicos

Lo que pasaCómo se arregla
Consola: Cannot read properties of nullEl id del HTML y el del JS no coinciden, falta la #, o el .js es de otra página.
Al pulsar no pasa nada y la consola no dice nadaEl src del <script> no coincide con el nombre del archivo. Pon console.log("clic"); dentro de las llaves para comprobarlo.
Al pulsar, lo escrito se borra y la página se recargaAl botón del formulario le falta type="button".
El mensaje sale sin lo que ha escrito el usuarioEl value se lee fuera de las llaves. Muévelo dentro (Alt + ↑/↓).
Una suma da 31 en lugar de 4Falta Number().
La clase se pone (F12 → Elements) pero no cambia nadaLa regla del CSS tiene otro nombre, o en classList has puesto el punto.
Consola: Unexpected token o Unexpected end of inputSobra o falta una llave o un paréntesis. Mayús + Alt + F para ordenar el código y verlo.
