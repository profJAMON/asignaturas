La receta de un botón

Casi todo lo que haréis con JavaScript sigue la misma receta de tres pasos:

  1. Buscar en la página los elementos que vas a usar.
  2. Esperar a que alguien pulse el botón.
  3. Hacer algo cuando lo pulse.

Hoy lo aplicamos a Pixel Kart: un botón que muestra un dato curioso del juego.

<button type="button" id="boton-dato">Ver un dato curioso</button>
<p id="dato"></p>
// 1. Buscar los elementos
let boton = document.querySelector("#boton-dato");
let dato = document.querySelector("#dato");

// 2. Esperar al clic
boton.addEventListener("click", function () {
    // 3. Hacer algo
    dato.textContent = "Turbo Rex fue diseñado por un chaval de 14 años.";
});

Al pulsar, en el párrafo vacío aparece: Turbo Rex fue diseñado por un chaval de 14 años.

Paso 1: buscar con querySelector

let boton = document.querySelector("#boton-dato");
  • document es la página.
  • querySelector busca en ella el primer elemento que cumpla lo que le pides.
  • Lo que va entre comillas es un selector, igual que en CSS: "#boton-dato" busca el elemento con id="boton-dato". La almohadilla # significa id, igual que el punto significa clase.
  • Lo que encuentra se guarda en una variable, para usarlo después.
⚠️ En el HTML: id="boton-dato", sin almohadilla. En JavaScript: "#boton-dato", con almohadilla. Es el mismo lío que con el punto de las clases.

Paso 2: esperar con addEventListener

boton.addEventListener("click", function () {
    // aquí dentro va lo que pasa al pulsar
});
  • addEventListener significa "quédate escuchando". Le dices qué esperar ("click") y qué hacer.
  • Lo que va entre las llaves { } de function () { } no se ejecuta al cargar la página: se ejecuta cada vez que se pulsa el botón.
  • Fíjate en cómo se cierra: });. La llave cierra la función, el paréntesis cierra addEventListener y el punto y coma acaba la orden.
💡 Copia esta estructura tal cual y cambia solo lo de dentro. Nadie la escribe de memoria las primeras veces.

Paso 3: cambiar un texto con textContent

dato.textContent = "Turbo Rex fue diseñado por un chaval de 14 años.";

textContent es el texto que hay dentro de un elemento. Si le das un valor con =, lo sustituye. Así puedes cambiar el texto de un párrafo, de un título o del propio botón:

boton.addEventListener("click", function () {
    dato.textContent = "Turbo Rex fue diseñado por un chaval de 14 años.";
    boton.textContent = "¡Ya lo sabes!";
});

El error más común

Si en la consola sale esto:

Uncaught TypeError: Cannot read properties of null (reading 'addEventListener')

significa que querySelector no encontró nada (null quiere decir "nada"). Las causas:

  • El id del HTML y el del JavaScript no coinciden letra a letra.
  • Falta la # en el JavaScript.
  • El <script> está en el <head> y no al final del <body>.
  • Ese archivo JS lo carga una página que no tiene ese botón. Por eso hacemos un archivo JS por página.

Antes de seguir

¿Qué busca document.querySelector("#resultado")?

El elemento de la página que tenga id="resultado".

Pones un console.log dentro de la función del addEventListener. ¿Cuándo sale el mensaje en la consola?

Cada vez que se pulsa el botón. Al cargar la página no sale nada.

¿Qué hace titulo.textContent = "Hola";?

Cambia el texto que hay dentro del elemento guardado en titulo por "Hola".

Reto de hoy

Añadid a vuestra web un botón que muestre un dato curioso de vuestro tema:

  • Un <button type="button"> y un párrafo vacío, cada uno con un id que diga qué es.
  • En el archivo JS de esa página, los tres pasos: buscar, esperar al clic y cambiar el texto.
  • Al pulsar el botón, aparece el dato en el párrafo y cambia el texto del propio botón.
  • Un comentario encima de cada paso (// 1. Buscar...).
  • La consola no muestra errores, ni al cargar ni al pulsar.
Pista 1: al pulsar no pasa nada y la consola no dice nada

Pon console.log("clic"); como primera línea dentro de la función. Si al pulsar no sale "clic", el problema está en el paso 1 o 2. Si sale, está en el paso 3.

Pista 2: sale "Cannot read properties of null"

Lee el apartado "El error más común" de esta sesión y comprueba las cuatro causas una a una.
