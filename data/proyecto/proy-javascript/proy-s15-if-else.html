Tomar decisiones: if y else

Hasta ahora, la página respondía siempre lo mismo. Con if (en inglés, "si") puede responder distinto según lo que pase:

let edad = 10;

if (edad >= 12) {
    console.log("Te puedes inscribir en el torneo.");
} else {
    console.log("Tienes que tener 12 años o más.");
}
Tienes que tener 12 años o más.
  • Entre paréntesis va la condición: una pregunta que solo puede ser verdadera o falsa. Aquí: "¿edad es mayor o igual que 12?".
  • Si es verdadera, se ejecuta lo de las primeras llaves.
  • Si es falsa, se ejecuta lo del else ("si no").

Cómo se compara

EscribesSignifica
a === ba es igual a b
a !== ba es distinto de b
a > b · a < bmayor que · menor que
a >= b · a <= bmayor o igual · menor o igual
⚠️ Un solo = guarda un valor (let edad = 10). Para comparar se usan tres: ===. Confundirlos es el error más típico con if.

Un if dentro de un botón

Lo normal es decidir al pulsar un botón, según lo que ha escrito el usuario. El torneo de Pixel Kart comprueba la edad antes de inscribir:

boton.addEventListener("click", function () {
    let alias = cajaAlias.value;
    let edad = Number(cajaEdad.value);

    if (edad >= 12) {
        mensaje.textContent = "¡Inscrito, " + alias + "! Nos vemos en la pista.";
    } else {
        mensaje.textContent = "Lo siento, " + alias + ": hay que tener 12 años o más.";
    }
});

Con RayoAzul y 14 años:

¡Inscrito, RayoAzul! Nos vemos en la pista.

Con RayoAzul y 10 años:

Lo siento, RayoAzul: hay que tener 12 años o más.

El if va dentro de las llaves del addEventListener, después de leer las cajas.

🤔 Antes de seguir: escribes if (edad = 12) y siempre entra en el if. ¿Por qué?

Con un solo = no comparas: guardas 12 en edad. Para comparar hay que escribir ===.

Más de dos caminos: else if

let puntos = 7;

if (puntos >= 9) {
    console.log("¡Campeón!");
} else if (puntos >= 5) {
    console.log("Buena carrera.");
} else {
    console.log("Sigue practicando.");
}
Buena carrera.

Se comprueban en orden, de arriba abajo, y solo se ejecuta el primer camino que sea verdadero. Con 7 puntos, el primero es falso y el segundo verdadero.

Contar aciertos

Para un test, se usa una variable que cuenta los aciertos. Empieza en 0 y cada respuesta correcta le suma 1:

let aciertos = 0;

if (pregunta1.value === "Turbo Rex") {
    aciertos = aciertos + 1;
}
if (pregunta2.value === "8") {
    aciertos = aciertos + 1;
}
  • aciertos = aciertos + 1 significa "coge lo que vale aciertos, súmale 1 y guárdalo otra vez".
  • Cada pregunta tiene su propio if, sin else: si falla, no se suma nada.
  • Lo de un <select> es texto: se compara con comillas, "8", y escrito exactamente igual que la opción.
  • let aciertos = 0; va dentro de las llaves del botón: así la cuenta empieza en 0 cada vez que pulsas.
🤔 Antes de seguir: puntos vale 9 en el ejemplo del else if. ¿Qué sale?

"¡Campeón!". Es la primera condición verdadera y ya no se miran las demás.

💡 Truco de VS Code: pon el cursor al lado de una llave { y VS Code marca con un recuadro su pareja }. Si el código se ve desordenado, pulsa Mayús + Alt + F: con las sangrías bien puestas se ve enseguida qué llave falta.
