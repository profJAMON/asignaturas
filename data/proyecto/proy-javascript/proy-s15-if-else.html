Tomar decisiones

Hasta ahora, la web respondía siempre lo mismo. Con if (en inglés, "si") puede responder distinto según lo que pase: si la edad es menor de 12, no te puedes inscribir; si aciertas, sumas un punto...

let edad = 10;

if (edad >= 12) {
    console.log("Te puedes inscribir en el torneo.");
} else {
    console.log("Tienes que tener 12 años o más.");
}
Tienes que tener 12 años o más.
  • Entre paréntesis va la condición: una pregunta que solo puede ser verdadera o falsa.
  • Si es verdadera, se ejecuta lo que hay entre las primeras llaves.
  • Si es falsa, se ejecuta lo que hay en el else ("si no"). El else es opcional.

Cómo se compara

EscribesSignifica
a === ba es igual a b
a !== ba es distinto de b
a > b / a < bmayor que / menor que
a >= b / a <= bmayor o igual / menor o igual
⚠️ Un solo = guarda un valor (let edad = 10). Para comparar se usan tres: ===. Confundirlos es el error más típico con if.

Más de dos caminos: else if

let puntos = 7;

if (puntos >= 9) {
    console.log("¡Campeón!");
} else if (puntos >= 5) {
    console.log("Buena carrera.");
} else {
    console.log("Sigue practicando.");
}

Se comprueban en orden, de arriba abajo, y solo se ejecuta el primer camino cuya condición sea verdadera. Con 7 puntos, la primera es falsa y la segunda verdadera: sale "Buena carrera.".

Un if dentro de un botón

Juntamos lo de las sesiones anteriores: leer el formulario y decidir. El torneo de Pixel Kart comprueba la edad antes de inscribir:

let cajaAlias = document.querySelector("#alias");
let cajaEdad = document.querySelector("#edad");
let boton = document.querySelector("#boton-inscribir");
let mensaje = document.querySelector("#mensaje");

boton.addEventListener("click", function () {
    let alias = cajaAlias.value;
    let edad = Number(cajaEdad.value);

    if (alias === "") {
        mensaje.textContent = "Escribe tu alias.";
    } else if (edad < 12) {
        mensaje.textContent = "Lo siento, " + alias + ": hay que tener 12 años o más.";
    } else {
        mensaje.textContent = "¡Inscrito, " + alias + "! Nos vemos en la pista.";
    }
});

alias === "" comprueba si la caja está vacía: dos comillas seguidas son un texto sin nada dentro.

Un mini test con puntos

Para un test, se usa una variable que cuenta los aciertos. Empieza en 0 y cada respuesta correcta le suma 1:

let pregunta1 = document.querySelector("#pregunta1");
let pregunta2 = document.querySelector("#pregunta2");
let botonTest = document.querySelector("#boton-test");
let resultado = document.querySelector("#resultado");

botonTest.addEventListener("click", function () {
    let aciertos = 0;

    if (pregunta1.value === "Turbo Rex") {
        aciertos = aciertos + 1;
    }
    if (pregunta2.value === "8") {
        aciertos = aciertos + 1;
    }

    if (aciertos === 2) {
        resultado.textContent = "¡Perfecto! Eres un experto en Pixel Kart.";
    } else {
        resultado.textContent = "Has acertado " + aciertos + " de 2. ¡Inténtalo otra vez!";
    }
});

aciertos = aciertos + 1 significa "coge lo que vale aciertos, súmale 1 y guárdalo otra vez en aciertos".

💡 El let aciertos = 0; va dentro de la función. Así, cada vez que se pulsa el botón, la cuenta empieza desde 0 y no se acumulan los puntos de la vez anterior.

Antes de seguir

¿Qué sale si puntos vale 9 en el ejemplo del else if?

"¡Campeón!". Es la primera condición verdadera y ya no se miran las demás.

Escribes if (edad = 12) y siempre entra en el if. ¿Por qué?

Con un solo = no comparas: guardas 12 en edad. Para comparar hay que escribir ===.

En el test, el select tiene la opción "turbo rex" en minúsculas y comparas con "Turbo Rex". ¿Cuenta como acierto?

No. Para === las mayúsculas cuentan: los dos textos tienen que ser exactamente iguales.

Reto de hoy

Haced que vuestra web responda distinto según lo que elija o escriba el usuario. Puede ser un mini test, una calculadora que da un consejo, una recomendación según lo elegido...

  • Al pulsar un botón, se leen datos del formulario con value.
  • Al menos un if con else if y else: 3 respuestas distintas como mínimo.
  • Si una caja se queda vacía, la web avisa en lugar de dar un resultado raro.
  • Comprobación: probáis a propósito las 3 respuestas y las 3 salen cuando toca.
  • La consola no muestra errores.
Pista 1: siempre sale la misma respuesta

Pon console.log( la variable que compruebas ) justo antes del if para ver qué vale de verdad. Quizá no es un número porque falta Number(), o tiene otra mayúscula.

Pista 2: sale "Unexpected token else"

Te sobra o te falta una llave antes del else. Cada { tiene que tener su }. Usa Mayús+Alt+F para ordenar el código y verlo más claro.
