Qué es JavaScript

Una web con HTML y CSS tiene contenido y aspecto. Pero todavía no hace nada: si pulsas un botón, no pasa nada.

JavaScript (JS) es un lenguaje de programación: le das órdenes al navegador y él las cumple, una detrás de otra. Con JS la web puede calcular, reaccionar a un clic, cambiar textos o esconder cosas.

LenguajeQué haceEjemplo
HTMLQué hayHay un botón
CSSCómo se veEl botón es naranja
JavaScriptQué haceAl pulsar el botón, sale un mensaje

Conectar un archivo JavaScript

Igual que el CSS, el JavaScript va en un archivo aparte. Cada página tiene su propio archivo JS, con el mismo nombre. En Pixel Kart, la página torneo.html tiene su torneo.js. En tus ejercicios, s12-ej1.html tiene su s12-ej1.js.

Se conecta con la etiqueta <script>, justo antes de cerrar el <body>:

<body>
    <h1>Torneo de Pixel Kart</h1>
    ...

    <script src="torneo.js"></script>
</body>

Va al final a propósito: así, cuando el JavaScript empieza a funcionar, todo el HTML de la página ya existe.

💡 Truco de VS Code: en el HTML, escribe script:src y pulsa Tab. VS Code escribe <script src=""></script> y deja el cursor entre las comillas, listo para el nombre del archivo.
🤔 Antes de seguir: ¿por qué el <script> va al final del <body> y no en el <head>?

Para que, cuando el JavaScript se ejecute, todo el HTML de la página ya exista y se pueda encontrar.

La consola

La consola es una ventana de Chrome donde JavaScript escribe mensajes. Ahí ves qué está pasando y ahí salen los errores.

  1. Abre la página con Live Server, como siempre.
  2. Pulsa F12. Si no pasa nada, botón derecho en la página → Inspeccionar.
  3. Se abre un panel. Arriba tiene pestañas: Elements, Console… Pulsa Console.

Para escribir en la consola se usa console.log:

console.log("¡Hola desde Pixel Kart!");
Elements   Console   Sources   Network
¡Hola desde Pixel Kart! torneo.js:1
✖ Uncaught ReferenceError: piloto is not defined torneo.js:3
  • Lo que va entre los paréntesis sale en la consola.
  • Los textos van siempre entre comillas.
  • Cada orden termina con punto y coma ;.
  • A la derecha sale el archivo y la línea: torneo.js:3 es "línea 3 de torneo.js".
  • Los errores salen en rojo. Es lo primero que tienes que mirar cuando algo no funciona.
💡 Truco de VS Code: en el archivo .js, escribe log y pulsa Tab. VS Code escribe console.log(); con el cursor dentro de los paréntesis.

Variables

Una variable es una caja con nombre donde guardas un dato para usarlo después:

let piloto = "Turbo Rex";
let vueltas = 3;

console.log(piloto);
console.log(vueltas);
Turbo Rex torneo.js:4
3 torneo.js:5
  • let crea la variable. Después va su nombre, un = y el valor que guarda.
  • Para usar el dato, escribe el nombre sin comillas.
  • Nombres: sin espacios ni tildes, y que digan qué guardan. Si son varias palabras, se juntan y cada una empieza en mayúscula: tiempoPorVuelta.
  • En la consola, los números salen en azul y los textos, en negro.
En internet verás también const en lugar de let. Hace casi lo mismo: crea una caja, pero su valor ya no se puede cambiar. Nosotros usamos siempre let.

Números y textos

No es lo mismo 5 que "5". Sin comillas es un número y se puede calcular. Con comillas es un texto.

OperaciónResultado
5 + 510 (suma)
"5" + "5"55 (junta los textos)
10 - 3 · 4 * 2 · 9 / 37 · 8 · 3

Se puede crear una variable a partir de otras:

let vueltas = 3;
let tiempoPorVuelta = 42;
let tiempoTotal = vueltas * tiempoPorVuelta;

console.log(tiempoTotal);
126
🤔 Antes de seguir: ¿qué sale en la consola con console.log("3" + 4)?

34: como uno de los dos es un texto, el + los junta en lugar de sumarlos.

Juntar textos y variables

El + con textos sirve para juntar un mensaje con el valor de una variable:

let piloto = "Turbo Rex";
let tiempoTotal = 126;

console.log(piloto + " tarda " + tiempoTotal + " segundos.");
Turbo Rex tarda 126 segundos.
⚠️ Fíjate en los espacios dentro de las comillas: " tarda ". Si no los pones, sale Turbo Rextarda126segundos.

Comentarios

En JavaScript, un comentario empieza por //. El navegador lo ignora. Sirve para explicar qué hace cada parte:

// Precio de la entrada al torneo
let precio = 10;

Igual que en HTML, Ctrl + / convierte la línea en comentario.
