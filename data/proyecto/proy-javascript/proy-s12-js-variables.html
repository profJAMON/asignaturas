Qué es JavaScript

Ya tenéis una web con contenido (HTML) y con aspecto (CSS). Pero todavía no hace nada: si pulsas el botón del formulario, no pasa nada.

JavaScript (JS) es un lenguaje de programación: le das órdenes al navegador y él las cumple una detrás de otra. Con JS la web puede calcular, reaccionar a un clic, cambiar textos o esconder cosas.

LenguajeQué haceEjemplo
HTMLQué hayHay un botón
CSSCómo se veEl botón es naranja
JavaScriptQué haceAl pulsar el botón, sale un mensaje

Conectar un archivo JavaScript

Igual que el CSS, el JavaScript va en un archivo aparte. Nosotros haremos un archivo JS para cada página que lo necesite, con el mismo nombre que la página. Para la página del torneo de Pixel Kart, torneo.html, el archivo será torneo.js.

Se conecta con la etiqueta <script>, justo antes de cerrar el <body>:

    <main>
        ...
    </main>

    <script src="torneo.js"></script>
</body>
</html>

Va al final a propósito: así, cuando el JavaScript empieza a funcionar, todo el HTML de la página ya existe y lo puede encontrar.

La consola

La consola es una ventana de Chrome donde JavaScript puede escribir mensajes. Es la herramienta más útil para saber qué está pasando. Se abre con F12 → pestaña Console.

Escribe esto en torneo.js, guarda y mira la consola de torneo.html:

console.log("¡Hola desde Pixel Kart!");
¡Hola desde Pixel Kart!
  • console.log(...) escribe en la consola lo que le pongas entre los paréntesis.
  • Los textos van siempre entre comillas.
  • Cada orden termina con punto y coma ;.
⚠️ Si JavaScript encuentra un error, lo escribe en rojo en la consola, con el número de línea. Acostúmbrate a tener la consola abierta siempre que trabajes con JS: es la primera cosa que tienes que mirar cuando algo no funciona.

Variables

Una variable es una caja con nombre donde guardas un dato para usarlo después:

let piloto = "Turbo Rex";
let vueltas = 3;
let tiempoPorVuelta = 42;

console.log(piloto);
console.log(vueltas * tiempoPorVuelta);
Turbo Rex
126
  • let crea la variable. Después va su nombre, un = y el valor que guarda.
  • Nombres de variables: sin espacios, sin tildes y que digan qué guardan. Si son varias palabras, se juntan y cada una empieza en mayúscula: tiempoPorVuelta.
  • Para usar el dato, escribe el nombre de la variable sin comillas.

Números y textos

No es lo mismo 5 que "5". Sin comillas es un número y se puede calcular. Con comillas es un texto.

OperaciónResultado
5 + 510
"5" + "5""55" (junta los textos)
10 - 3, 4 * 2, 9 / 37, 8, 3

El + con textos sirve para juntar un mensaje con el valor de una variable:

let piloto = "Turbo Rex";
let vueltas = 3;
let tiempoPorVuelta = 42;
let tiempoTotal = vueltas * tiempoPorVuelta;

console.log(piloto + " tarda " + tiempoTotal + " segundos en acabar la carrera.");
Turbo Rex tarda 126 segundos en acabar la carrera.
💡 Fíjate en los espacios dentro de las comillas: " tarda ". Si no los pones, sale Turbo Rextarda126segundos.

Comentarios

En JavaScript, un comentario empieza por //. El navegador lo ignora. Úsalos para explicar qué hace cada parte:

// Precio de la entrada al torneo, sin IVA
let precio = 10;
let precioConIva = precio * 1.21; // el IVA es el 21 %

Antes de seguir

¿Por qué el <script> va al final del <body> y no en el <head>?

Para que, cuando el JavaScript se ejecute, todo el HTML de la página ya exista y se pueda encontrar.

¿Qué sale en la consola con console.log("3" + 4)?

34: como uno de los dos es un texto, el + los junta en lugar de sumarlos.

Escribes console.log(piloto) y sale en rojo "piloto is not defined". ¿Qué significa?

Que no existe ninguna variable con ese nombre: no la has creado con let, o está escrita distinta (por ejemplo, Piloto con mayúscula).

Reto de hoy

Cread el archivo JavaScript de la página donde tenéis el formulario y haced un cálculo de vuestro tema que salga en la consola. Por ejemplo: el precio de unas entradas con IVA, cuántos minutos dura un disco entero, los puntos de un equipo después de varias jornadas...

  • Un archivo .js con el mismo nombre que la página del formulario, conectado al final de su <body>.
  • Al menos 3 variables con nombres que digan qué guardan, y al menos una con un texto.
  • Una variable nueva que se calcula a partir de otras (con +, -, * o /).
  • Un console.log que muestra una frase completa, con espacios bien puestos, que junta texto y variables.
  • Al menos 2 comentarios que expliquen el cálculo.
  • La consola no muestra ningún error en rojo.
Pista 1: la consola está vacía

¿Estás mirando la consola de la página correcta? ¿El src del <script> coincide con el nombre del archivo? Si el archivo no se encuentra, la consola dice 404.

Pista 2: sale "Uncaught SyntaxError"

Hay algo mal escrito en la línea que indica: casi siempre unas comillas o un paréntesis sin cerrar.
