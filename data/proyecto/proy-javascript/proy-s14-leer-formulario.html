1. ¿Dónde se pone el <script> y por qué?

Justo antes de cerrar el <body>, para que el HTML ya exista cuando el JavaScript lo busque.

2. ¿Qué diferencia hay entre let edad = 15; y let edad = "15";?

La primera guarda un número (se puede calcular con él). La segunda guarda un texto.

3. ¿Cuáles son los tres pasos de la receta de un botón?

Buscar los elementos con querySelector, esperar al clic con addEventListener y hacer algo dentro de la función.

4. Tienes <p id="saludo"></p>. Escribe cómo lo buscarías y cómo pondrías dentro el texto "Hola". 
let saludo = document.querySelector("#saludo");
saludo.textContent = "Hola";
5. La consola dice "Cannot read properties of null". ¿Qué ha pasado?

Que querySelector no ha encontrado el elemento: el id no coincide, falta la # o el script no está al final.

Leer lo que escribe el usuario: value

Con textContent escribíamos en la página. Ahora queremos leer lo que el visitante ha escrito en una caja del formulario. Para eso está value:

<label for="alias">Tu alias:</label>
<input type="text" id="alias">

<label for="piloto">Piloto favorito:</label>
<select id="piloto">
    <option>Turbo Rex</option>
    <option>Nube Veloz</option>
    <option>Chispa</option>
</select>

<button type="button" id="boton-inscribir">Inscribirme</button>
<p id="mensaje"></p>
// 1. Buscar los elementos
let cajaAlias = document.querySelector("#alias");
let cajaPiloto = document.querySelector("#piloto");
let boton = document.querySelector("#boton-inscribir");
let mensaje = document.querySelector("#mensaje");

// 2. Esperar al clic
boton.addEventListener("click", function () {
    // 3. Leer lo que ha escrito y responder
    let alias = cajaAlias.value;
    let piloto = cajaPiloto.value;
    mensaje.textContent = "¡Hola, " + alias + "! Te has inscrito con " + piloto + ".";
});

Si el visitante escribe RayoAzul, elige Chispa y pulsa el botón, aparece: ¡Hola, RayoAzul! Te has inscrito con Chispa.

  • cajaAlias.value es lo que hay escrito en la caja en ese momento.
  • En un <select>, value es la opción elegida.
  • El value se lee dentro de la función. Si lo lees fuera, lo lees al cargar la página, cuando la caja todavía está vacía.
⚠️ Fíjate en los nombres: cajaAlias es la caja (el elemento de la página) y alias es lo que hay escrito dentro (un texto). Poner nombres distintos evita muchos líos.

Números que vienen de una caja

Todo lo que se lee con value es texto, aunque la caja sea type="number". Si quieres hacer cuentas, primero tienes que convertirlo con Number():

let cajaVueltas = document.querySelector("#vueltas");
let botonCalcular = document.querySelector("#boton-calcular");
let resultado = document.querySelector("#resultado");

botonCalcular.addEventListener("click", function () {
    let vueltas = Number(cajaVueltas.value);
    let segundos = vueltas * 42;
    resultado.textContent = "Tardarás unos " + segundos + " segundos.";
});

Antes de seguir

¿Qué diferencia hay entre textContent y value?

textContent es el texto de dentro de un elemento como un párrafo; lo usamos para escribir. value es lo escrito o elegido en una caja de formulario; lo usamos para leer.

Lees cajaAlias.value fuera de la función y siempre sale vacío. ¿Por qué?

Porque se lee al cargar la página, antes de que el usuario escriba nada. Hay que leerlo dentro de la función del clic.

El usuario escribe 10 y 5 en dos cajas, y tu suma da 105. ¿Qué falta?

Convertir los dos valores con Number() antes de sumar.
