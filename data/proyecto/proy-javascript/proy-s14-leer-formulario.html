Leer lo que escribe el usuario: value

Con textContent escribíamos en la página. Ahora queremos leer lo que el visitante ha escrito en una caja del formulario. Para eso está value. Así funciona el formulario del torneo de Pixel Kart:

<form>
    <label for="alias">Tu alias:</label>
    <input type="text" id="alias">
    <button type="button" id="boton-inscribir">Inscribirme</button>
</form>
<p id="mensaje"></p>
// 1. Buscar los elementos
let cajaAlias = document.querySelector("#alias");
let boton = document.querySelector("#boton-inscribir");
let mensaje = document.querySelector("#mensaje");

// 2. Esperar al clic
boton.addEventListener("click", function () {
    // 3. Leer la caja y responder
    let alias = cajaAlias.value;
    mensaje.textContent = "¡Hola, " + alias + "! Ya estás inscrito.";
});

¡Hola, RayoAzul! Ya estás inscrito.

  • cajaAlias.value es lo que hay escrito en la caja en ese momento.
  • El value se lee dentro de las llaves. Si lo lees fuera, lo lees al cargar la página, cuando la caja todavía está vacía.
  • El botón lleva type="button", como viste en la sesión 6. Sin él, al pulsar se recarga la página y se borra todo.
⚠️ Fíjate en los nombres: cajaAlias es la caja (el elemento de la página) y alias es lo que hay escrito dentro (un texto). Poner nombres distintos evita muchos líos.
🤔 Antes de seguir: ¿qué diferencia hay entre textContent y value?

textContent es el texto de dentro de un elemento como un párrafo: lo usamos para escribir. value es lo escrito o elegido en una caja de formulario: lo usamos para leer.

Ejercicio 3 — Bienvenida

Crea s14-ej3.html y s14-ej3.js. Al escribir tu alias y pulsar "Saludar", la página te saluda con tu alias.

  • ① Un <form> con <label>, un <input id="alias"> y un botón.
  • ② Un <p id="saludo"> que muestra lo escrito en la caja.
  • ③ Antes de pulsar, el párrafo está vacío.
  • ④ El botón tiene type="button".
Pista 1: el mensaje sale, pero sin lo que he escrito

Pista 2: sale "undefined" en el mensaje

Si lo has hecho bien: escribes otro alias, pulsas otra vez y el saludo cambia.

💡 Truco de VS Code: para mover una línea, pon el cursor en ella y pulsa Alt + ↑ o Alt + ↓. Así metes rápido una línea dentro de las llaves, sin cortar y pegar.

Leer un desplegable

En un <select>, value es la opción elegida. Se lee igual que una caja:

<select id="piloto">
    <option>Turbo Rex</option>
    <option>Nube Veloz</option>
    <option>Chispa</option>
</select>
let piloto = cajaPiloto.value;
mensaje.textContent = alias + " correrá con " + piloto + ".";

RayoAzul correrá con Chispa.

Números que vienen de una caja

Todo lo que se lee con value es texto, aunque la caja sea type="number". Para hacer cuentas, primero se convierte con Number():

let vueltas = Number(cajaVueltas.value);
let segundos = vueltas * 42;
resultado.textContent = "Tardarás unos " + segundos + " segundos.";
Si el usuario escribe 3Resultado
cajaVueltas.value + 131 (junta textos)
Number(cajaVueltas.value) + 14 (suma)
🤔 Antes de seguir: el usuario escribe 10 y 5 en dos cajas y tu suma da 105. ¿Qué falta?

Convertir los dos valores con Number() antes de sumar.
