Repetir sin copiar y pegar

Imagina que quieres escribir en la consola las vueltas de una carrera de 5 vueltas:

console.log("Vuelta 1");
console.log("Vuelta 2");
console.log("Vuelta 3");
console.log("Vuelta 4");
console.log("Vuelta 5");

Funciona, pero ¿y si la carrera tiene 50 vueltas? ¿Y si el número de vueltas lo escribe el usuario? Para eso existen los bucles: repiten un trozo de código las veces que haga falta.

El bucle for

for (let vuelta = 1; vuelta <= 5; vuelta = vuelta + 1) {
    console.log("Vuelta " + vuelta);
}
Vuelta 1
Vuelta 2
Vuelta 3
Vuelta 4
Vuelta 5

Entre los paréntesis hay tres partes, separadas por punto y coma:

ParteSignifica
let vuelta = 1Empieza con una variable que vale 1.
vuelta <= 5Repite mientras esto sea verdad.
vuelta = vuelta + 1Después de cada vuelta, suma 1 a la variable.

Lo que va entre llaves se repite. En cada repetición la variable vale un número distinto (1, 2, 3, 4 y 5), y la puedes usar dentro.

⚠️ Si la condición nunca deja de ser verdad (por ejemplo, te olvidas de sumar 1), el bucle no termina nunca y la pestaña se queda colgada. No pasa nada: cierra la pestaña, arregla el código y vuelve a abrirla.

Escribir HTML con un bucle: innerHTML

Para que el resultado salga en la página y no en la consola, necesitamos una orden nueva. textContent solo escribe texto; innerHTML escribe etiquetas HTML. Y con += añades al final en lugar de sustituir:

<ul id="lista-vueltas"></ul>
let listaVueltas = document.querySelector("#lista-vueltas");

for (let vuelta = 1; vuelta <= 5; vuelta = vuelta + 1) {
    listaVueltas.innerHTML += "<li>Vuelta " + vuelta + "</li>";
}
  • Vuelta 1
  • Vuelta 2
  • Vuelta 3
  • Vuelta 4
  • Vuelta 5

En cada repetición se añade un <li> nuevo dentro de la lista vacía. El resultado es una lista de verdad, con el estilo de vuestro CSS.

El usuario decide cuántas veces

Juntamos todo lo del curso: un formulario, un botón, value, Number() y un bucle. En Pixel Kart, el usuario escribe cuántas vueltas quiere y la web le genera una tabla con el tiempo acumulado:

<label for="vueltas">Número de vueltas:</label>
<input type="number" id="vueltas" min="1" max="20">
<button type="button" id="boton-tabla">Generar tabla</button>

<table id="tabla-tiempos"></table>
let cajaVueltas = document.querySelector("#vueltas");
let botonTabla = document.querySelector("#boton-tabla");
let tabla = document.querySelector("#tabla-tiempos");

botonTabla.addEventListener("click", function () {
    let total = Number(cajaVueltas.value);

    // Vaciar la tabla y poner la fila de encabezados
    tabla.innerHTML = "<tr><th>Vuelta</th><th>Tiempo total</th></tr>";

    for (let vuelta = 1; vuelta <= total; vuelta = vuelta + 1) {
        let segundos = vuelta * 42;
        tabla.innerHTML += "<tr><td>" + vuelta + "</td><td>" + segundos + " s</td></tr>";
    }
});

Si el usuario escribe 3 y pulsa el botón:

VueltaTiempo total
142 s
284 s
3126 s
  • La primera línea usa = y no +=: sustituye todo lo que había. Así, si el usuario pulsa dos veces, la tabla no sale repetida.
  • Dentro del bucle se usa += para añadir una fila en cada vuelta.
💡 Cuidado con las comillas: el HTML va dentro de comillas dobles, así que dentro del HTML no puedes usar comillas dobles para atributos. Si necesitas una clase, usa comillas simples dentro: "<li class='destacado'>".

Antes de seguir

¿Cuántas veces se repite for (let i = 1; i <= 10; i = i + 1)?

10 veces: con i valiendo 1, 2, 3... hasta 10.

¿Qué diferencia hay entre lista.innerHTML = "..." y lista.innerHTML += "..."?

Con = se sustituye todo lo que había dentro. Con += se añade al final de lo que ya había.

Pulsas el botón dos veces y la lista sale repetida. ¿Qué falta?

Vaciar la lista al principio de la función, con lista.innerHTML = "";, antes del bucle.

Reto de hoy

Usad un bucle para generar una lista o una tabla en vuestra web, relacionada con vuestro tema. Ideas: una cuenta atrás, las jornadas de una liga, la tabla de puntos de un campeonato, las raciones de una receta para 1, 2, 3... personas, una tabla de multiplicar de precios.

  • Una lista (<ul> u <ol>) o una tabla vacía con id.
  • Un bucle for que añade elementos con innerHTML +=.
  • Dentro del bucle se usa la variable del bucle (el número cambia en cada elemento).
  • El usuario decide cuántos elementos se generan, escribiendo un número en una caja y pulsando un botón.
  • Comprobación: si pulsáis el botón dos veces, el resultado no sale repetido.
  • La consola no muestra errores.
Pista 1: no sale nada

Pon console.log(total); antes del bucle. Si sale 0 o NaN, el problema es la lectura del número: revisa el id de la caja y el Number().

Pista 2: salen las etiquetas escritas como texto, con < y >

Estás usando textContent. Para escribir HTML hay que usar innerHTML.
