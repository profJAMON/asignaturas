Cambiar el aspecto desde JavaScript

Con textContent cambiábamos textos. Ahora vamos a cambiar cómo se ve algo: esconderlo, mostrarlo o cambiarle los colores.

La idea es muy sencilla y aprovecha lo que ya sabéis:

  1. En el CSS preparas una clase con el aspecto nuevo.
  2. Desde JavaScript, al pulsar un botón, pones o quitas esa clase al elemento.

classList

classList son las clases que tiene un elemento. Tiene tres órdenes:

OrdenQué hace
elemento.classList.add("oculto")Le pone la clase.
elemento.classList.remove("oculto")Le quita la clase.
elemento.classList.toggle("oculto")Si no la tiene, se la pone; si la tiene, se la quita. Como un interruptor.
⚠️ En classList el nombre de la clase va sin punto: toggle("oculto"). El punto solo se pone en el CSS.

Mostrar y ocultar

En Pixel Kart, los trucos del juego están escondidos hasta que pulsas un botón:

<button type="button" id="boton-trucos">Mostrar trucos</button>

<section id="trucos" class="oculto">
    <h2>Trucos</h2>
    <p>Derrapa justo antes de la curva para ganar un turbo.</p>
</section>
.oculto {
    display: none;
}
let botonTrucos = document.querySelector("#boton-trucos");
let trucos = document.querySelector("#trucos");

botonTrucos.addEventListener("click", function () {
    trucos.classList.toggle("oculto");
});
  • display: none hace que el elemento no se vea ni ocupe sitio.
  • La sección empieza con class="oculto", así que al cargar la página está escondida.
  • Cada clic en el botón quita o pone la clase: se muestra, se esconde, se muestra...

Que el botón diga lo que va a hacer

Queda mejor si el botón cambia su texto. Con classList.contains("oculto") preguntas si el elemento tiene esa clase, y lo usas en un if:

botonTrucos.addEventListener("click", function () {
    trucos.classList.toggle("oculto");

    if (trucos.classList.contains("oculto")) {
        botonTrucos.textContent = "Mostrar trucos";
    } else {
        botonTrucos.textContent = "Ocultar trucos";
    }
});

Modo oscuro

La misma idea sirve para cambiar los colores de toda la página: se pone una clase en el <body>.

body.modo-oscuro {
    background-color: #111111;
    color: #eeeeee;
}

body.modo-oscuro .tarjeta {
    background-color: #222222;
}
let botonModo = document.querySelector("#boton-modo");

botonModo.addEventListener("click", function () {
    document.body.classList.toggle("modo-oscuro");
});
  • body.modo-oscuro (sin espacio) significa "el body cuando tiene la clase modo-oscuro".
  • body.modo-oscuro .tarjeta (con espacio) significa "las tarjetas que están dentro de ese body".
  • document.body es el <body> de la página: no hace falta buscarlo con querySelector.
El modo oscuro así solo dura mientras estás en esa página: al cambiar de página o recargar, vuelve al modo normal. Recordarlo entre páginas se puede hacer, pero es más complicado y no lo veremos este curso.

Antes de seguir

¿Qué diferencia hay entre classList.add y classList.toggle?

add siempre pone la clase. toggle la pone si no la tiene y la quita si la tiene.

Escribes trucos.classList.toggle(".oculto") y no funciona. ¿Por qué?

Sobra el punto. En classList el nombre de la clase va sin punto.

Pulsas el botón y la clase se pone (lo ves con F12), pero no cambia nada en pantalla. ¿Dónde está el problema?

En el CSS: la regla de esa clase no existe, está mal escrita o tiene otro nombre.

Reto de hoy

Añadid a vuestra web una segunda cosa que funcione con JavaScript: mostrar y ocultar algo, modo oscuro, o cualquier otro cambio de aspecto al pulsar un botón.

  • Una clase nueva en estilos.css con el aspecto que se va a activar.
  • Un botón que, al pulsarlo, pone y quita esa clase con classList.toggle.
  • El texto del botón cambia según el estado, usando classList.contains en un if.
  • Comprobación: pulsáis varias veces seguidas y funciona siempre, en los dos sentidos.
  • La consola no muestra errores.
Pista 1: ¿cómo veo si la clase se pone o no?

Pulsa F12 → pestaña Elements y busca el elemento. Al pulsar el botón, verás aparecer y desaparecer la clase en su etiqueta.

Pista 2: el modo oscuro cambia el fondo, pero las tarjetas siguen igual

Tus tarjetas tienen su propio color de fondo. Añade una regla body.modo-oscuro .tu-clase-de-tarjeta { ... } para cambiarlas también.
