Hoy: con JavaScript cambias cómo se ve algo al pulsar un botón: resaltarlo, mostrarlo, esconderlo o pasar la página a modo oscuro. Trabajas solo, en tu carpeta de ejercicios.

Cambiar el aspecto desde JavaScript

La idea aprovecha lo que ya sabes de CSS:

  1. En el CSS preparas una clase con el aspecto nuevo.
  2. Desde JavaScript, al pulsar un botón, pones o quitas esa clase al elemento.

classList son las clases que tiene un elemento. Tiene tres órdenes:

OrdenQué hace
elemento.classList.add("oculto")Le pone la clase.
elemento.classList.remove("oculto")Le quita la clase.
elemento.classList.toggle("oculto")Si no la tiene, se la pone; si la tiene, se la quita. Como un interruptor.
⚠️ En classList el nombre de la clase va sin punto: add("oculto"). El punto solo se pone en el CSS: .oculto { … }.

Poner una clase: add

En Pixel Kart, al pulsar un botón se resalta el piloto ganador:

.ganador {
    background-color: gold;
    font-weight: bold;
}
botonGanador.addEventListener("click", function () {
    turboRex.classList.add("ganador");
});

Pista 1: ¿cómo veo si la clase se pone?

Pulsa F12 → pestaña Elements y busca el párrafo. Al pulsar el botón, verás aparecer class="resaltado" en su etiqueta.

Pista 2: la clase se pone, pero no cambia nada

El problema está en el CSS: falta el <link>, o la clase tiene otro nombre en el CSS y en el JS.

Si lo has hecho bien: al recargar la página, el aviso vuelve a estar normal hasta que pulsas.

Mostrar y ocultar: add y remove

Con display: none, un elemento no se ve ni ocupa sitio. Si el elemento empieza con esa clase, al cargar está escondido:

<ul id="trucos" class="oculto">
    <li>Derrapa antes de la curva para ganar un turbo.</li>
</ul>
.oculto {
    display: none;
}
botonMostrar.addEventListener("click", function () {
    trucos.classList.remove("oculto");
});

botonOcultar.addEventListener("click", function () {
    trucos.classList.add("oculto");
});

Para mostrar, se quita la clase oculto. Para ocultar, se pone.

🤔 Antes de seguir: escribes trucos.classList.remove(".oculto") y no funciona. ¿Por qué?

Sobra el punto. En classList el nombre de la clase va sin punto.

Un interruptor: toggle

Con toggle basta un solo botón: cada clic pone la clase si no está y la quita si está.

botonTrucos.addEventListener("click", function () {
    trucos.classList.toggle("oculto");
});

Un elemento también se puede cambiar a sí mismo: el botón puede ponerse o quitarse una clase.

Modo oscuro

La misma idea sirve para cambiar los colores de toda la página: se pone una clase en el <body>.

body.modo-oscuro {
    background-color: #111111;
    color: #eeeeee;
}

body.modo-oscuro .tarjeta {
    background-color: #333333;
}
botonModo.addEventListener("click", function () {
    document.body.classList.toggle("modo-oscuro");
});
  • body.modo-oscuro (sin espacio) es "el body cuando tiene la clase modo-oscuro".
  • body.modo-oscuro .tarjeta (con espacio) es "las tarjetas que están dentro de ese body".
  • document.body es el <body> de la página: no hace falta buscarlo con querySelector.
El modo oscuro así solo dura mientras estás en esa página: al recargar o cambiar de página, vuelve al modo normal.
💡 Truco de VS Code: selecciona una palabra (por ejemplo, oculto) y pulsa Ctrl + D: se selecciona también la siguiente vez que aparece. Cada Ctrl + D añade otra. Escribe y las cambias todas a la vez. Muy útil para cambiar el nombre de una clase o de una variable sin dejarte ninguna.

Ejercicio 4 — Club de astronomía

El ejercicio más largo de hoy: junta todo. Crea s16-ej4.html, s16-ej4.css y s16-ej4.js. Un botón cambia la página a modo oscuro y otro muestra el lugar de la salida, que empieza escondido.

  • ① Dos botones, #boton-modo y #boton-lugar, dentro de un párrafo.
  • ② Un <div class="tarjeta"> con fondo gris claro, padding y esquinas redondeadas.
  • ③ Dentro de la tarjeta, un <p id="lugar" class="oculto">.
  • ④ "Cambiar modo" pone y quita modo-oscuro en el body; la tarjeta también cambia de color.
  • ⑤ "Ver el lugar" muestra el párrafo escondido.
  • ⑥ Volver a pulsar "Cambiar modo" devuelve los colores claros.
Pista 1

En el CSS van cuatro reglas: .tarjeta, .oculto, body.modo-oscuro y body.modo-oscuro .tarjeta.

Pista 2: el fondo cambia, pero la tarjeta sigue gris claro

Falta la regla body.modo-oscuro .tarjeta, o le falta el espacio entre modo-oscuro y .tarjeta.

Si lo has hecho bien: los dos botones funcionan en cualquier orden, sin errores en la consola.
