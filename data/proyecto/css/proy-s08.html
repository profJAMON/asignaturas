Separar contenido y aspecto

El HTML dice qué es cada cosa y estilos.css decide cómo se ve. Enlaza el mismo archivo desde las tres páginas.

<link rel="stylesheet" href="css/estilos.css">
body { font-family: sans-serif; }
h1 { color: steelblue; }
.tarjeta { background: white; }

Reto del día

  1. Crea una carpeta css y un único estilos.css.
  2. Enlázalo desde las tres páginas.
  3. Prueba un selector de etiqueta y uno de clase.

Comprobación: cambiar una regla modifica las tres páginas.

Aplícalo en tu web

Elegid una paleta de dos o tres colores, una fuente legible y nombres de clase que expliquen su función.
