La caja de cada elemento

Todo elemento ocupa contenido, padding, borde y margen. El padding respira dentro de la caja; el margin separa una caja de otra.

.seccion { margin: 20px 0; padding: 16px; border: 1px solid #ccc; background: #f5f5f5; }

Reto del día

  1. Convierte dos secciones en tarjetas.
  2. Añade espacio interior, borde y fondo.
  3. Usa el margen para que no se peguen.

Comprobación: el contenido no toca el borde y las tarjetas se distinguen sin usar saltos de línea repetidos.

Aplícalo en tu web

Aplica el mismo patrón a la lista, la tabla o los bloques de información sin duplicar reglas innecesariamente.
