Distribuir con Flexbox

Flexbox organiza elementos hijos en una fila o columna y distribuye el espacio disponible.

nav ul { display: flex; gap: 12px; list-style: none; }
.tarjetas { display: flex; flex-wrap: wrap; gap: 16px; }
.tarjeta { flex: 1 1 220px; }

Reto del día

  1. Haz que el menú sea horizontal.
  2. Coloca tres tarjetas en una fila cuando haya espacio.
  3. Comprueba que se reorganizan en una pantalla estrecha.

Comprobación: el menú no necesita espacios manuales y las tarjetas no se salen de la pantalla.

Aplícalo en tu web

Usa Flexbox para el menú y para las tres imágenes o bloques principales.
