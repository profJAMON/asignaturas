Para qué sirve un formulario

Un formulario es la parte de una web donde el visitante escribe o elige algo: buscar, apuntarse a un torneo, hacer un test, calcular un precio…

Hoy haremos solo la parte de HTML: las cajas, las opciones y el botón. Al pulsar el botón todavía no pasará nada: lo haremos funcionar con JavaScript.

Las piezas de un formulario

<form>
    <label for="alias">Tu alias:</label>
    <input type="text" id="alias" placeholder="Por ejemplo: RayoAzul">
    <button type="button">Inscribirme</button>
</form>

EtiquetaPara qué sirve
<form>Agrupa todo el formulario.
<label>El texto que explica qué hay que poner en la caja.
<input>Una caja para escribir. No se cierra.
<button>Un botón.
  • placeholder es el texto gris de ejemplo que se ve dentro de la caja vacía.
  • El for del <label> es igual que el id de su caja. Así quedan unidos: si pulsas el texto, el cursor salta a la caja.
  • El id es un nombre único: no puede haber dos iguales en una página. Ponle nombres que digan qué es: id="alias" ✅, id="caja1" ❌. Con JavaScript encontrarás cada caja por su id.
  • El botón lleva siempre type="button". Sin eso, al pulsarlo la página se recarga y se borra lo escrito.

Más tipos de caja

El atributo type del <input> cambia qué se puede escribir:

typeQué hace
textTexto normal.
numberSolo números. Con min y max pones límites.
emailUn correo electrónico.
dateUna fecha, con calendario.
checkboxUna casilla para marcar.

<select id="piloto">
    <option>Turbo Rex</option>

<textarea id="opinion" rows="3" cols="30"></textarea>

  • <select> es un desplegable; cada <option> es una opción.
  • <textarea> es una caja grande, para escribir varias líneas. Esta sí se cierra. rows son las líneas de alto y cols, los caracteres de ancho.

Para que cada pregunta salga en su propia línea, mete cada pareja de <label> y caja en un <p>.

Privacidad en los formularios

⚠️ Las webs de las parejas estarán publicadas. En un formulario nunca se piden datos personales: nada de nombre y apellidos, teléfono, dirección ni DNI. Se piden alias, opiniones, gustos, cantidades…
