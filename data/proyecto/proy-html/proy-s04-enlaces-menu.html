La etiqueta <a>

Un enlace se crea con la etiqueta <a>. El atributo href dice adónde lleva, y el texto de dentro es lo que se ve y se pulsa:

<a href="personajes.html">Ver los personajes</a>

Tres tipos de enlace

TipoEjemploAdónde lleva
A otra página tuyahref="circuitos.html"A otro archivo de tu carpeta. Se escribe como las rutas de las imágenes.
A otra webhref="https://es.wikipedia.org"Fuera de tu web. Siempre empieza por https://.
Dentro de la misma páginahref="#modos"Al elemento que tenga id="modos", en la misma página.

Los enlaces a otras webs conviene abrirlos en una pestaña nueva, para que el visitante no salga de la tuya. Se hace con target="_blank":

<a href="https://es.wikipedia.org/wiki/Kart" target="_blank">Qué es un kart (Wikipedia)</a>

Una imagen que es un enlace

Si metes una <img> dentro de un <a>, al pulsar la imagen se abre el enlace. Es típico en los logos, que llevan a la portada:

<a href="index.html"><img src="img/logo.png" alt="Logo de Pixel Kart: volver al inicio"></a>

Una web de varias páginas

Hasta ahora teníais solo index.html. Una web de verdad tiene varias páginas, y cada una es un archivo .html distinto dentro de la misma carpeta:

pixel-kart/
├── index.html        ← Inicio
├── personajes.html   ← Personajes
├── circuitos.html    ← Circuitos
└── img/

Crear una página nueva copiando index.html

Así la página nueva ya tiene la estructura mínima bien hecha y no hay que escribirla otra vez:

  1. En el panel de la izquierda de VS Code, pulsa con el botón derecho sobre index.html → Copy (copiar).
  2. Pulsa con el botón derecho en un espacio en blanco del panel, debajo de los archivos → Paste (pegar). Aparece index copy.html.
  3. Botón derecho sobre index copy.html → Rename… (cambiar nombre). Escribe el nombre de la página nueva, por ejemplo personajes.html, y pulsa Intro. Minúsculas, sin espacios ni tildes, y que acabe en .html.
  4. Pulsa sobre el archivo nuevo para abrirlo y cambia: el <title>, el <h1> y todo el contenido de la página. Deja igual la estructura (<!DOCTYPE>, <head>, <body>).
  5. Guarda con Ctrl + S.
  6. Para verla en Chrome, con Live Server encendido, cambia el final de la dirección: 127.0.0.1:5500/personajes.html. Cuando tengáis el menú, ya podréis ir de una página a otra pulsando los enlaces.

El menú

El menú es una lista de enlaces a todas las páginas, dentro de la etiqueta <nav> (de navigation). Va al principio del <body>, dentro de un <header>:

<body>
    <header>
        <nav>
            <a href="index.html">Inicio</a>
            <a href="personajes.html">Personajes</a>
            <a href="circuitos.html">Circuitos</a>
        </nav>
    </header>

    <main>
        <h1>Pixel Kart</h1>
        <p>El juego de karts más rápido del instituto.</p>
    </main>
</body>

Inicio Personajes Circuitos

Pixel Kart

El juego de karts más rápido del instituto.

  • <header> es la cabecera de la página: lo que se repite arriba en todas.
  • <nav> agrupa los enlaces del menú.
  • <main> es el contenido principal, lo que cambia de una página a otra.

Estas etiquetas no cambian nada visualmente, pero ordenan el código y ayudan a los lectores de pantalla. Además, con CSS pondremos el menú bonito y en fila.

⚠️ El menú tiene que ser exactamente el mismo en todas las páginas. Cuando lo tengas bien en index.html, cópialo y pégalo en las demás. Si cambias algo del menú, tendrás que cambiarlo en todas.

Antes de seguir

¿Qué diferencia hay entre href="circuitos.html" y href="https://circuitos.com"?

El primero lleva a un archivo de tu propia web, dentro de tu carpeta. El segundo lleva a otra web de Internet.

Pulsas el enlace a personajes.html y sale "Cannot GET /personajes.html". ¿Qué ha pasado?

El archivo no existe con ese nombre: no lo has creado, no lo has guardado o el nombre no coincide letra a letra con el href.

¿Para qué sirve target="_blank"?

Para que el enlace se abra en una pestaña nueva y el visitante no pierda tu web.

Reto de hoy

Convertid vuestra portada en una web de verdad:

  • Las 3 páginas de vuestra ficha creadas, cada una con su <title>, su <h1> y al menos un párrafo propio.
  • En todas las páginas, el mismo menú dentro de <header> y <nav>, con enlaces a las 3.
  • El contenido de cada página dentro de <main>.
  • Al menos un enlace a otra web relacionada con vuestro tema, que se abra en una pestaña nueva.
  • Comprobación: desde cualquier página puedes llegar a cualquier otra con el menú, sin que ningún enlace dé error.
Pista 1: el enlace da error

Compara letra a letra el href con el nombre del archivo en el panel de VS Code, incluida la extensión .html.

Pista 2: en una página el menú está bien y en otra no

No copiaste el menú actualizado. Copia el <header> entero de la página que funciona y pégalo en las demás, sustituyendo el viejo.
