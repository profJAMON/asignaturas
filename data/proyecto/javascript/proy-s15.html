Elegir entre dos resultados

if comprueba una condición. else indica qué hacer cuando no se cumple.

if (respuesta.value === 'si') {
  resultado.textContent = 'Resultado A';
} else {
  resultado.textContent = 'Resultado B';
}

Reto del día

  1. Prepara una pregunta o dato que pueda tener dos resultados.
  2. Lee la respuesta con value.
  3. Muestra un mensaje distinto en cada caso.

Comprobación: pruebas las dos opciones y obtienes mensajes diferentes.

Aplícalo en tu web

Construye un mini test o una calculadora sencilla. Evita añadir operadores o estructuras que aún no hemos trabajado.
