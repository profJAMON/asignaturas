Una clase que se enciende y se apaga

CSS define el aspecto y JavaScript decide cuándo añadir o quitar una clase.

boton.addEventListener('click', function () {
  document.body.classList.toggle('oscuro');
});

Reto del día

Añade un modo oscuro o un botón que muestre y oculte una sección. Define primero la clase en CSS y después usa classList.toggle.

Comprobación: al pulsar dos veces, la página vuelve a su estado inicial.

Aplícalo en tu web

El control debe tener texto claro y funcionar en todas las páginas donde se use.
