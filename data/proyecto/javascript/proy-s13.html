El primer botón

Selecciona un elemento, escucha el clic y cambia su texto.

const boton = document.querySelector('#boton');
const mensaje = document.querySelector('#mensaje');
boton.addEventListener('click', function () {
  mensaje.textContent = 'Aquí está el dato curioso';
});

Reto del día

  1. Añade un botón y un párrafo con id.
  2. Conecta ambos desde script.js.
  3. Haz que el clic muestre un dato curioso.

Comprobación: el texto cambia sin recargar la página.

Aplícalo en tu web

El dato debe pertenecer al tema y aparecer dentro de una página visible.
