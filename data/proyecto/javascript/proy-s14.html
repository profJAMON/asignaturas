Leer value

Un campo de formulario guarda lo escrito en su propiedad value. Tras las vacaciones, empieza revisando el selector, el evento y los id.

const nombre = document.querySelector('#nombre');
const boton = document.querySelector('#enviar');
const respuesta = document.querySelector('#respuesta');
boton.addEventListener('click', function () {
  respuesta.textContent = 'Has elegido: ' + nombre.value;
});

Reto del día

Haz que vuestro formulario muestre un mensaje usando lo que ha escrito o elegido el usuario.

Comprobación: el mensaje cambia al probar dos respuestas diferentes.

Aplícalo en tu web

El formulario debe estar relacionado con el tema y funcionar en la página publicada.
