Repetir sin copiar y pegar

Un bucle for repite una acción. Es útil para generar varias filas o elementos a partir de datos.

for (let i = 0; i < 3; i++) {
  lista.innerHTML += '<li>Elemento ' + (i + 1) + '</li>';
}

Reto del día

  1. Prepara una lista vacía o una tabla.
  2. Usa un for sencillo para añadir al menos tres elementos.
  3. Comprueba que no aparecen elementos de más al recargar.

Comprobación: puedes explicar qué significan el inicio, la condición y el incremento del bucle.

Aplícalo en tu web

Genera una lista o una tabla de datos del tema. Mantén el contenido visible, no solo en la consola.
